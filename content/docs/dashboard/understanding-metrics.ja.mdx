**ホーム**はConnektのダッシュボードです。目標、活動、パイプライン、売上がブロックで表示され、自由に並べ替えられます。サイドバーの**ホーム**をクリックして開きます。

**ホーム**を開くには、**個人ダッシュボードの閲覧**、**チームダッシュボードの閲覧**、**会社全体のダッシュボードの閲覧**のうち、少なくとも1つの権限が必要です。

## 数値の表示対象を選ぶ [#choose-whose-numbers-you-see]

管理者、オフィスの管理者、チームのリーダーには、右上に表示範囲のメニューが表示されます。初期設定は**マイダッシュボード**です。メニューを開いて、次のいずれかを選択します。

- **オフィス：**オフィスに所属する全員です。
- **チーム：**チームに所属する全員です。
- **ユーザー：**特定の1人です。1対1の面談前などに確認できます。

メニューには、**London › Sales**のように選択した対象が表示されます。選択を解除すると、**マイダッシュボード**に戻ります。管理対象のメンバーがいない場合は、自分の数値のみが表示され、表示範囲のメニューは表示されません。

## 数値の表示通貨を選ぶ [#choose-the-currency-for-figures]

表示範囲のメニューの横にある通貨ボタンをクリックします。**数値の表示通貨**メニューでは、次の選択肢を選べます。

- **会社の通貨：**会社の正式な数値に使用する通貨です。これが初期設定です。
- **自分の通貨：**プロフィールに設定されている通貨です。
- オフィスを選択している場合は、そのオフィスの通貨です。

通貨の変更は、金額の表示にのみ反映されます。集計対象の商談は変わりません。会社の通貨は、管理者が**設定 → 売上と為替**で設定します。[オフィスと通貨](/ja/advanced/offices-and-currency)を参照してください。

## カードの期間を変更する [#change-a-cards-period]

多くのカードやグラフには個別の期間選択機能があり、それぞれ異なる期間で表示できます。**週**、**月**、**四半期**、**年**から選択します。月、四半期、年では、過去の四半期など、表示する期間も指定できます。

## ダッシュボードの表示内容 [#whats-on-the-dashboard]

初期レイアウトには、次のブロックが含まれます。

| ブロック | 表示内容 |
|---|---|
| **目標の達成状況** | 現在有効な売上目標の達成状況です。[目標と指標の目標値](/ja/dashboard/goal-progress)を参照してください。 |
| **売上（四半期累計）**と**売上（年初来累計）** | 四半期累計と年初来累計の売上を、目標と比較して表示します。 |
| **候補者面談** | 候補者との面談数を、目標と比較して表示します。 |
| **履歴書送付数** | クライアントに送付した履歴書の数を、目標と比較して表示します。 |
| **履歴書送付から面接への移行率** | 履歴書の送付から面接に進んだ割合を、目標と比較して表示します。 |
| **営業活動** | アプローチ、商談のための面談、契約済み企業を表示します。 |
| **自分の指標** | 自分の候補者、企業、求人、面接を表示します。 |
| **採用担当者別売上ランキング** | 個人売上に基づくリクルーターのランキングです。 |
| **候補者の活動状況** | 候補者の活動の推移を表示します。 |
| **採用ファネル** | 推薦、面接、成約を表示します。 |
| **月別売上** | 月ごとの売上の内訳です。 |
| **エリア別売上** | エリア別の売上ランキングです。 |
| **候補者紹介数上位の採用担当者** | 候補者紹介数に基づくリクルーターのランキングです。 |

次のブロックも追加できます。

| ブロック | 表示内容 |
|---|---|
| **成績上位者** | ソーシング担当者、担当者、リクルーターそれぞれの成績上位者を表示します。 |
| **転換率** | 推薦から成約への転換率です。 |
| **今後の面接予定** | 今週予定されている面接を表示します。 |
| **請求状況** | 期間ごとに、請求済み、支払い済み、未払い、支払期限超過の請求書を表示します。 |
| **採用ファネル** | 推薦から成約までの各ステージの転換率です。 |
| **パイプライン予測** | 進行中の商談をステージ別に表示し、進行中の内定も表示します。 |
| **組織全体の推移** | 全社の候補者、企業、成約に関する12か月間の推移です。 |
| **全社概要** | 全社の候補者、企業、成約、転換率の指標です。 |

売上の数値には、取り消された成約は含まれません。

## ブロックの表示に必要な権限 [#who-sees-which-blocks]

各ブロックには、**目標の達成状況**や**年初来累計売上**など、個別の権限があります。ロールにそのブロックの権限がない場合、ダッシュボードにも**カスタマイズ**にも表示されません。**チーム**プラン以上では、管理者が**設定 → 権限**でこれらの権限を変更できます。[権限のカスタマイズ](/ja/team/customising-permissions)を参照してください。

<Note>
  **請求状況**、**成績上位者**、**転換率**は高度な分析機能を使用するため、**Business**プランが必要です。[プランの比較](/ja/billing/plans-compared)を参照してください。
</Note>

## ダッシュボードをカスタマイズする [#customise-your-dashboard]

レイアウトは自分専用です。変更しても、他のユーザーには影響しません。

<Steps>
  <Step title="カスタマイズを開く">
    右上の**カスタマイズ**をクリックします。**ダッシュボードをカスタマイズ**パネルが開きます。
  </Step>
  <Step title="ブロックを並べ替える">
    **表示中のブロック（ドラッグで並べ替え）**で、ブロックをドラッグして希望の順序に並べ替えます。
  </Step>
  <Step title="ブロックの表示と非表示を切り替える">
    ブロックのスイッチで非表示にします。非表示にしたブロックは**非表示**に移動し、そこでスイッチをオンにすると再表示できます。
  </Step>
  <Step title="ブロックを追加する">
    **ブロックを追加**で、追加したいブロックの横にある**追加**をクリックします。
  </Step>
  <Step title="保存する">
    **レイアウトを保存**をクリックします。初期レイアウトに戻すには、保存する前に**リセット**をクリックします。
  </Step>
</Steps>

<Tip>
  **システム管理**権限がある場合、**カスタマイズ**には**目標値と目標**も表示され、**目標**と**指標の目標値**へのショートカットを利用できます。
</Tip>
