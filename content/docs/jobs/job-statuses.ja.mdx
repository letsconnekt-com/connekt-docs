各求人には、募集の状況を示すステータスが1つ設定されています。新規求人のステータスは**表示**です。ステータスは手動で変更できるほか、成約の追加・変更・削除に応じてConnektが自動で更新します。

## 8種類のステータス [#the-8-statuses]

| ステータス | 主な用途 |
|---|---|
| **表示** | 募集を開始し、候補者を探している状態です。新規求人の初期ステータスです。 |
| **進行中** | 候補者の選考が進んでいる状態です。 |
| **一部採用決定** | 複数名を募集する求人で、一部の採用が決定した状態です。残りの募集は継続します。 |
| **採用決定** | 募集人数すべての採用が決定した状態です。 |
| **保留** | クライアントの採用凍結などにより、募集を一時停止している状態です。 |
| **募集終了** | 募集を終了した状態です。 |
| **キャンセル済み** | クライアントが募集を取りやめた状態です。 |
| **無効** | 現在、対応していない求人です。 |

## 求人ステータスを変更する [#change-a-jobs-status]

ステータスは3か所から変更できます。

<Tabs>
  <Tab title="求人ページ">
    <Steps>
      <Step title="求人を開く">
        サイドバーの**求人**をクリックし、求人を開きます。
      </Step>
      <Step title="ステータスバッジをクリックする">
        求人のヘッダーにあるステータスバッジをクリックします。**求人ステータスを変更**メニューが開きます。
      </Step>
      <Step title="ステータスを選択する">
        変更先のステータスをクリックします。
      </Step>
      <Step title="変更を確定する">
        確認ダイアログで**ステータスを変更**をクリックします。
      </Step>
    </Steps>
  </Tab>
  <Tab title="求人一覧">
    **求人**一覧の**ステータス**列にあるドロップダウンを使います。ステータスを選択すると、すぐに変更が保存されます。
  </Tab>
  <Tab title="複数の求人">
    <Steps>
      <Step title="求人を選択する">
        **求人**一覧で、各求人の横にあるチェックボックスをオンにします。
      </Step>
      <Step title="ステータスを変更する">
        **ステータスを変更**をクリックし、変更先のステータスを選択します。選択したすべての求人に適用されます。
      </Step>
    </Steps>
  </Tab>
</Tabs>

手動で変更したステータスは、求人の**履歴**タブに記録されます。

## ステータスの自動変更 [#automatic-status-changes]

Connektは求人の有効な成約数を集計し、**募集人数**と比較します。ステータスが**入社済み**または**まもなく入社**の成約が有効な成約として扱われます。

| 有効な成約数 | 変更後のステータス |
|---|---|
| なし | **表示** |
| 1件以上で、募集人数未満 | **一部採用決定** |
| 募集人数と同数 | **採用決定** |

この判定は、求人の成約を作成したとき、成約のステータスを変更したとき、または成約を削除したときに実行されます。募集人数が複数の求人では、ステータスバッジの横にある更新ボタンで手動でも実行できます。

<Warning>
  自動更新では、手動で設定したステータスも含め、求人の現在のステータスが上書きされます。たとえば、求人を**募集終了**に設定した後、その求人の唯一の成約を削除すると、ステータスは**表示**に戻ります。成約を変更した後は、求人のステータスを確認してください。
</Warning>

## 新たに候補者を推薦できる求人 [#which-jobs-accept-new-submissions]

求人の**推薦**タブでは、ステータスが**表示**、**進行中**、**一部採用決定**のいずれかの場合にのみ、**候補者を推薦**を使用できます。それ以外のステータスでは、ボタンが無効になり、「募集終了の求人には候補者を推薦できません」と表示されます。また、この3つのステータスのいずれかに戻すまでは、このタブで推薦ステータスを変更することもできません。

<Note>
  この制限は、求人ページにのみ適用されます。候補者の**推薦**タブから**求人に推薦**を使う場合は、どのステータスの求人でも選択できます。候補者ページから推薦する際は、事前に求人ステータスを確認してください。[候補者を推薦する](/ja/submissions/submitting-a-candidate)を参照してください。
</Note>

AIマッチングでもステータスが使われます。候補者レコードの**募集中の求人とマッチング**では、**表示**または**一部採用決定**の求人のみが提案されます。[候補者と求人をマッチングする](/ja/candidates/matching-candidates-to-jobs)を参照してください。

## ステータスで求人を探す [#finding-jobs-by-status]

ステータスを変更しても、求人が削除されることはありません。募集終了、キャンセル済み、無効の求人でも、推薦、成約、メモ、履歴は保持されます。これらの求人を探すには、**求人**一覧を**ステータス**で絞り込みます。

<Info>
  求人を削除する権限があるユーザーは、求人の**⋯**メニューまたは一括操作用の**操作**メニューから削除できます。削除した求人はConnektに表示されなくなります。求人への対応をやめたいだけの場合は、削除せずにステータスを変更してください。
</Info>
