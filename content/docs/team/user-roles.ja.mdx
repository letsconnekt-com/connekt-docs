Connektの各ユーザーには、1つのロールが割り当てられます。ロールによって、表示できるレコード、変更できる内容、開ける設定など、デフォルトの権限が決まります。このページでは、デフォルトの権限について説明します。Teamプラン以上では、管理者が権限を変更できます。

## ロール一覧 [#role-reference]

| ロール | デフォルトのアクセス権限 |
|---|---|
| **最高管理者** | すべての権限を持ちます。設定からの割り当てや変更はできず、権限の編集もできません。 |
| **管理者** | すべてのレコードと設定にアクセスできます。**設定 → プラン**と請求、**ユーザー管理**、**権限**、**組織**も含まれます。ワークスペースを作成したユーザーは管理者になります。 |
| **業務状況** | 管理・監督のために全社の情報を閲覧できます。すべての候補者、企業、コンタクト、求人、商談に加え、全社ダッシュボードと財務ダッシュボードを表示できます。レコードの編集と**ユーザー管理**の利用ができます。候補者、企業、コンタクト、求人、商談の作成はできず、プラン、権限、その他の管理者設定にはアクセスできません。 |
| **上司** | コンサルタント系ロールのすべての操作に加え、チームのダッシュボードと商談の表示、レコードの担当者の変更、他のユーザーのメモの編集と削除、**署名**の利用ができます。**ユーザー管理**は開けません。 |
| **プリンシパルコンサルタント** | デフォルトの権限はコンサルタントと同じです。 |
| **シニアコンサルタント** | デフォルトの権限はコンサルタントと同じです。 |
| **コンサルタント** | すべての候補者、企業、コンタクト、求人を表示できます。これらの作成と編集、メモの追加、自分の商談および割り当てられた商談の操作ができます。レコードの削除や**署名**の利用はできません。 |
| **採用担当者** | デフォルトの権限はコンサルタントと同じです。 |
| **リサーチャー** | すべての候補者を表示でき、候補者の追加もできますが、候補者プロフィールの編集やメモの追加はできません。自分に割り当てられた求人と商談のみ表示できます。サイドバーに**企業**と**コンタクト**は表示されません。 |
| **ユーザー** | デフォルトでは、候補者、企業、求人、商談にアクセスできません。自分に割り当てられたコンタクトの表示と、成約へのメモや添付ファイルの追加ができます。 |

<Note>
  プリンシパルコンサルタント、シニアコンサルタント、コンサルタント、リクルーターの初期権限は同じです。職位を区別するために異なる名称を使うことも、[権限をカスタマイズ](/ja/team/customising-permissions)して違いを設けることもできます。
</Note>

## 管理者系ロールでできること [#what-admin-roles-can-do]

- **請求**：最高管理者と管理者は、**設定 → プラン**と**設定 → 利用状況**を開けます。[プランの比較](/ja/billing/plans-compared)をご覧ください。
- **ユーザー**：最高管理者、管理者、業務状況ロールのユーザーは、**設定 → ユーザー管理**でユーザーの招待、ロールの変更、ユーザーの無効化と再有効化ができます。
- **権限**：ロールの権限を編集できるのは、最高管理者と管理者のみです。[権限のカスタマイズ](/ja/team/customising-permissions)をご覧ください。

## リサーチャーと求人 [#researchers-and-jobs]

リサーチャーが表示できるのは、自分に割り当てられた求人のみです。リサーチャーに求人へのアクセスを許可するには、その求人にリサーチャーを追加します。[求人へのチームメンバーの割り当て](/ja/jobs/assigning-team-members)をご覧ください。

## 休暇の承認 [#leave-approvals]

ロールによって、休暇を承認できるユーザーも決まります。最高管理者と管理者は、ほとんどの申請を承認できます。業務状況ロールと上司ロールのユーザーは、自分が管理するチームからの申請を承認できます。その他のロールは休暇を承認できません。[休暇申請の承認](/ja/time-off/approving-leave)をご覧ください。

## 招待時にロールを選択する [#choose-a-role-when-you-invite-someone]

**設定 → ユーザー管理 → ユーザーを招待**からユーザーを招待するときに、フォームで**役割**を選択します。[チームの招待](/ja/getting-started/inviting-your-team)をご覧ください。

## ユーザーのロールを変更する [#change-someones-role]

<Steps>
  <Step title="ユーザー管理を開く">
    **設定 → ユーザー管理**を開きます。
  </Step>
  <Step title="対象のユーザーを探す">
    名前やメールアドレスで検索するか、ロールで絞り込みます。
  </Step>
  <Step title="ロールを変更する">
    対象のユーザーの横にある**⋯**をクリックし、**ロールを変更**を選択します。**新しいロール**を選択し、**ロールを更新**をクリックします。
  </Step>
</Steps>

自分自身のロールは変更できません。また、最高管理者のロールも変更できません。

<Tip>
  ロールの権限がおおむね適切でも、一部を調整したい場合は、そのユーザーに対して個別の権限を許可または拒否できます。[権限のカスタマイズ](/ja/team/customising-permissions#override-permissions-for-one-person)をご覧ください。
</Tip>
