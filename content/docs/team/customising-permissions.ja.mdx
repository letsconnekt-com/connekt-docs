---

各ロールにはデフォルトの権限が設定されています。チームの運用に合わない場合は、ロール全体の権限を変更するか、特定のユーザーに個別の権限を設定できます。デフォルトの権限については、[ユーザーロール](/ja/team/user-roles)をご覧ください。

<Info>
  ロールの権限を編集するには、**Team**プラン以上が必要です。**設定 → 権限**を開けるのは、特権管理者と管理者のみです。
</Info>

## ロールの権限を変更する [#change-a-roles-permissions]

<Steps>
  <Step title="権限を開く">
    **設定 → 権限**に移動します。
  </Step>
  <Step title="ロールを選択する">
    上部のドロップダウンからロールを選択します。特権管理者以外のすべてのロールを編集できます。
  </Step>
  <Step title="権限を探す">
    カテゴリーを開いて権限を確認するか、**権限を検索...**に入力します。概要には、そのロールで有効になっている権限の数が表示されます。
  </Step>
  <Step title="権限を変更する">
    個々の権限をオンまたはオフにします。カテゴリー全体を変更するには、そのカテゴリーの**すべて**または**なし**を使います。ロールのすべての権限を変更するには、**すべて有効化**または**すべて無効化**を使います。
  </Step>
  <Step title="保存する">
    画面下部にバーが表示され、**未保存の変更がある項目**としてロールが示されます。**変更を保存**をクリックして変更を適用するか、**変更を破棄**をクリックして元に戻します。
  </Step>
</Steps>

保存した変更は、そのロールのすべてのユーザーに適用されます。

<Warning>
  保存する前に別のロールに切り替えると、未保存の変更は失われます。
</Warning>

## 権限のカテゴリー [#permission-categories]

| カテゴリー | 対象範囲 |
|---|---|
| **ダッシュボード** | 個人、チーム、企業のダッシュボード、財務データ、およびそのロールに表示されるホームダッシュボードのウィジェットです。 |
| **候補者** | 候補者の閲覧、作成、編集、削除、担当者、メモ、添付ファイルです。 |
| **企業** | 企業の閲覧、作成、編集、削除、担当者、メモ、添付ファイルです。 |
| **コンタクト** | コンタクトの閲覧、作成、編集、削除、主要コンタクト、メモ、添付ファイルです。 |
| **求人** | すべての求人または担当求人の閲覧、求人の作成、編集、削除、メモ、添付ファイル、推薦です。 |
| **商談** | 個人、チーム、企業、または担当する商談の閲覧、商談の財務データ、および商談の作成、編集、削除です。 |
| **成約** | 成約のメモと添付ファイルです。 |
| **システム** | **システム管理**（プラン、権限、組織などの管理者設定）、**チーム管理**（**ユーザー管理**）、**ユーザー設定**、**レポートの閲覧**、**高度な分析**です。 |
| **業務状況** | **業務管理ダッシュボードの閲覧**です。 |
| **電子署名** | **書類の作成**です。有効にすると、サイドバーに**署名**が表示されます。 |
| **チェックリスト** | ホームの初期設定チェックリストに表示されるステップです。 |

## 設定例 [#examples]

<AccordionGroup>
  <Accordion title="コンサルタントが署名依頼の書類を送信できるようにする">
    コンサルタント、リクルーター、リサーチャーには、デフォルトでは**署名**が表示されません。ロールを選択し、**電子署名**を開き、**書類の作成**をオンにして保存します。すると、サイドバーに**署名**が表示されます。
  </Accordion>
  <Accordion title="上司が候補者を削除できるようにする">
    デフォルトで候補者を削除できるのは、特権管理者と管理者のみです。**上司**を選択し、**候補者**を開き、**候補者プロフィールを削除**をオンにして保存します。
  </Accordion>
  <Accordion title="ロールのダッシュボードで売上を非表示にする">
    ロールを選択し、**ダッシュボード**を開いて、**四半期累計売上**や**年初来累計売上**などのウィジェットをオフにします。保存すると、そのロールのホームダッシュボードにこれらのウィジェットが表示されなくなります。
  </Accordion>
</AccordionGroup>

## 特定のユーザーに個別の権限を設定する [#override-permissions-for-one-person]

同じロールのほかのユーザーとは異なるアクセス権が必要な場合は、個別の権限設定を使います。個別の権限設定を変更しても、そのユーザーのロールは変わりません。

<Steps>
  <Step title="ユーザー管理を開く">
    **設定 → ユーザー管理**に移動し、対象のユーザーを探します。
  </Step>
  <Step title="個別の権限設定を開く">
    対象ユーザーの横にある**⋯**をクリックし、**個別の権限設定を管理**を選択します。
  </Step>
  <Step title="各権限を設定する">
    各権限で、**デフォルト**（ロールの設定に従う）、**付与**、**拒否**のいずれかを選択します。**権限を検索...**を使うと、目的の権限をすばやく見つけられます。
  </Step>
  <Step title="保存する">
    フッターに、個別に設定されている権限の数が表示されます。**変更を保存**をクリックします。
  </Step>
</Steps>

個別の権限設定は、常にロールの設定より優先されます。個別の設定を解除するには、**デフォルト**に戻します。

<Note>
  特権管理者、管理者、業務担当ユーザーは、**個別の権限設定を管理**を開くことができます。権限を**付与**できるのは、特権管理者と管理者のみです。業務担当ユーザーは、権限を拒否するか、デフォルトに戻すことだけができます。
</Note>
