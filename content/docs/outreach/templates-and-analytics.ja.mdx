アウトリーチページでは、**シーケンス**の隣に**テンプレート**と**分析**のタブがあります。テンプレートを使うと、効果的なメールを複数のシーケンスで再利用できます。分析では、アウトリーチの成果を確認できます。アウトリーチを開くには、サイドバーの**アウトリーチ**をクリックするか、**G**、**O**の順にキーを押します。

アウトリーチは**Team**以上のプランで利用できます。[プランの比較](/ja/billing/plans-compared)をご覧ください。

## テンプレート [#templates]

アウトリーチのテンプレートは、シーケンスで再利用できるメールです。テンプレートはワークスペース内の全員と共有されます。

各テンプレートのカードには、テンプレート名、件名、本文の冒頭が表示されます。カードの下部には、シーケンスのメールで使用された回数と、開封・返信された割合が表示されます。

**テンプレートを検索…**でテンプレートを検索できます。

### テンプレートを作成する [#create-a-template]

<Steps>
  <Step title="新規テンプレートを作成する">
    **テンプレート**タブで、**新規テンプレート**をクリックします。
  </Step>
  <Step title="詳細を入力する">
    **名前**、**件名**、**本文**を入力します。すべて必須項目です。
  </Step>
  <Step title="パーソナライズする">
    トークンのボタンをクリックして、件名または本文にパーソナライズ用トークンを挿入します。**プレビュー**をクリックすると、サンプル情報が入ったメールを確認できます。
  </Step>
  <Step title="署名を設定する">
    このテンプレートから作成するステップに送信者の署名を追加する場合は、**デフォルトで送信者のメール署名を含める**を選択します。
  </Step>
  <Step title="保存する">
    **テンプレートを作成**をクリックします。
  </Step>
</Steps>

ファイルを添付するには、作成後にテンプレートをもう一度開き、**ファイルを添付**をクリックします。テンプレートを保存するまでは、ファイルを添付できません。

### テンプレートの変数 [#template-variables]

テンプレートでは、シーケンスのステップと同じパーソナライズ用トークンを使用します。二重の波括弧で囲んで入力するか、エディター内のボタンをクリックします。

| ボタン | トークン |
|---|---|
| **名** | `{{first_name}}` |
| **姓** | `{{last_name}}` |
| **現在の勤務先** | `{{company}}` |
| **現在の役職** | `{{title}}` |
| **募集中のポジション** | `{{role}}` |
| **所在地** | `{{location}}` |
| **リクルーター名** | `{{recruiter_name}}` |
| **求人企業** | `{{job_company}}` |
| **勤務地** | `{{job_location}}` |

トークンは、シーケンスからメールが送信されるときに実際の情報に置き換わります。各トークンに入る情報については、[パーソナライズ用トークン](/ja/outreach/email-sequences#personalization-tokens)をご覧ください。

### シーケンスでテンプレートを使用する [#use-a-template-in-a-sequence]

シーケンスビルダーで**+**ボタンをクリックし、**テンプレートからメールを作成**を選択します。テンプレートを検索して選択します。Connektがテンプレートを新しいメールステップにコピーします。[メールシーケンス](/ja/outreach/email-sequences#email-steps)をご覧ください。

<Note>
  作成されたステップはコピーです。ステップを編集してもテンプレートは変更されません。また、後からテンプレートを編集しても、作成済みのステップは変更されません。
</Note>

### テンプレートを編集・複製・削除する [#edit-duplicate-or-delete-a-template]

テンプレートのカードをクリックして編集し、**変更を保存**をクリックします。カードの**⋯**メニューからも操作できます。

- **編集**でテンプレートを開きます。
- **複製**で、名前に「(copy)」が付いたコピーを作成します。
- **削除**で、確認後にテンプレートを削除します。

<Info>
  アウトリーチのテンプレートは、受信トレイで使用するメールテンプレートとは別のものです。受信トレイのテンプレートを管理するには、[受信トレイの使い方](/ja/outreach/using-the-inbox#use-email-templates)をご覧ください。
</Info>

## 分析 [#analytics]

**分析**タブには、自分のシーケンスだけでなく、ワークスペース全体のアウトリーチの状況が表示されます。上部で期間を**過去7日間**、**過去30日間**、**過去90日間**から選択します。

| 指標 | 表示内容 |
|---|---|
| **メール送信数** | 選択した期間にシーケンスから送信されたメールの数です。 |
| **開封済み** | 送信されたメールのうち、開封されたメールの数です。 |
| **返信あり** | 送信されたメールのうち、返信があったメールの数です。 |
| **返信率** | メール送信数に対して返信があったメールの割合です。 |

**日別送信数**のグラフには、選択した期間の各日の**送信済み**、**開封済み**、**返信あり**の件数が表示されます。

### 成果を確認できるその他の場所 [#other-places-to-see-results]

- **シーケンス**タブの上部には、ワークスペース全体の**有効なシーケンス**、**配信中の候補者**、**登録者総数**、**平均返信率**が表示されます。
- **シーケンス**タブの各行には、そのシーケンスの**登録済み**、**配信中**、**返信率**が表示されます。
- シーケンス内のヘッダーには、最初のメールが送信されると、メール送信数と開封・返信された割合が表示されます。

<Tip>
  一部のメールアプリは開封トラッキングをブロックするため、開封数が実際よりも少なく表示されることがあります。シーケンスの成果を測るうえで、返信が最も信頼できる指標です。
</Tip>
