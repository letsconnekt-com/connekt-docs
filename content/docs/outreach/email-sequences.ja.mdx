---

メールシーケンスは、登録した候補者ごとにConnektが実行する一連のステップです。ステップでは、自分のメールアカウントからのパーソナライズされたメールの送信、指定日数の待機、開封やクリックの確認、手動で行うタスクの作成ができます。候補者が返信すると、その候補者のシーケンスは自動的に停止します。

アウトリーチを開くには、サイドバーの**アウトリーチ**をクリックするか、**G**、**O**の順にキーを押します。シーケンスは**シーケンス**タブにあります。

## 始める前に [#before-you-start]

アウトリーチでは、接続した自分のアカウントからメールを送信します。次のものが必要です。

- **Team**プラン以上。[プランの比較](/ja/billing/plans-compared)をご覧ください。
- 送信が有効になっている、接続済みのGmailアカウント。[メールを接続する](/ja/integrations/connecting-email)をご覧ください。
- [プロジェクト](/ja/projects/creating-a-project)に追加済みの候補者。候補者はプロジェクトからシーケンスに登録するためです。

アカウントが接続されていない場合、アウトリーチにはシーケンスの代わりに**メールを接続**が表示されます。接続済みでも送信が有効になっていない場合は、**送信はまだ有効になっていません**と表示されます。再接続して、送信権限を付与してください。

<Warning>
  現在、アウトリーチからの送信はGmailのみに対応しています。Outlookアカウントではメールをレコードに同期できますが、シーケンスのメールは送信できません。
</Warning>

## シーケンスタブ [#the-sequences-tab]

**シーケンス**タブには、自分が作成したシーケンスが表示されます。チームの他のメンバーは、自分のシーケンスを表示したり編集したりできません。上部のカードには、ワークスペース全体の**有効なシーケンス**、**配信中の候補者**、**登録者総数**、**平均返信率**が表示されます。

各シーケンスの一覧には、ステータス、**担当者**、**登録済み**、**配信中**、**返信率**が表示されます。**シーケンスを検索...**とステータスフィルターを使って、シーケンスを探します。

### シーケンスのステータス [#sequence-statuses]

| ステータス | 意味 |
|---|---|
| **下書き** | 新規作成された、まだ有効化されていないシーケンスです。何も送信されません。 |
| **有効** | シーケンスが実行中です。登録されているすべての候補者に対してステップが実行されます。 |
| **一時停止中** | 何も送信されません。シーケンスを再び有効化すると、停止したところから再開します。 |
| **アーカイブ済み** | 使用を終了したシーケンスです。候補者を登録することはできません。 |

一覧からシーケンスを一時停止または有効化するには、その行の一時停止ボタンまたは再生ボタンをクリックします。**⋯**メニューには、**編集**、**複製**、**削除**があります。

## シーケンスを作成する [#create-a-sequence]

<Steps>
  <Step title="新しいシーケンスを作成する">
    **シーケンス**タブで、**新規シーケンス**をクリックします。
  </Step>
  <Step title="名前を付ける">
    **名前**を入力し、必要に応じて**説明**も入力します。**作成**をクリックします。シーケンスビルダーが開きます。
  </Step>
  <Step title="ステップを追加する">
    キャンバス上の**+**ボタンをクリックすると、その位置にステップが追加されます。ステップをクリックすると、右側のパネルで編集できます。
  </Step>
  <Step title="配信スケジュールを確認する">
    ヘッダーのスケジュールボタンをクリックして、メールを送信できる時間帯を選択します。[配信スケジュールを設定する](#set-the-delivery-schedule)をご覧ください。
  </Step>
  <Step title="保存して有効化する">
    **保存**をクリックして変更を保存します。準備ができたら、**有効化**をクリックします。有効化すると、シーケンスも保存されます。
  </Step>
</Steps>

シーケンスの名前を変更するには、ビルダーで名前にカーソルを合わせ、鉛筆アイコンをクリックします。

<Note>
  シーケンスを有効化するには、メールステップまたは手動ステップが少なくとも1つ必要です。メールステップには件名とメッセージが必要です。手動ステップにはメッセージが必要です。
</Note>

## ステップの種類 [#step-types]

| ステップ | 動作 |
|---|---|
| **メールステップ** | 接続済みのアカウントからメールを送信します。 |
| **テンプレートからメールを作成** | [アウトリーチテンプレート](/ja/outreach/templates-and-analytics)の内容が入力されたメールステップを追加します。 |
| **LinkedInメッセージ（手動）** | LinkedInメッセージを手動で送信するタスクを作成します。 |
| **LinkedInつながり申請（手動）** | LinkedInのつながり申請を手動で送信するタスクを作成します。 |
| **電話（手動）** | 候補者に電話をかけるタスクを作成します。 |
| **手動タスク** | 自分で入力した指示を含むタスクを作成します。 |
| **待機** | 指定した日数だけシーケンスを一時停止します。 |
| **条件** | 候補者が条件を満たす場合のみ続行します。満たさない場合、その候補者のシーケンスは終了します。 |

### メールステップ [#email-steps]

メールステップには、次の設定があります。

- **ステップ名**：「初回メール」など、ステップのラベルです。
- **待機期間（日）**：前のステップの後、送信までに待機する期間です。
- **件名**とメッセージ：トークンボタンを使って内容をパーソナライズします。**プレビュー**をクリックすると、サンプル情報を使ったメールを確認できます。
- **添付ファイル**：**ファイルを添付**をクリックします。新しいステップにファイルを添付するには、先にシーケンスを一度保存する必要があります。
- **送信者のメール署名を含める**：メールの末尾に自分の署名を追加します。[プロフィールとメール署名](/ja/account/profile-and-email-signature)をご覧ください。
- **配信停止リンクを含める**：配信停止リンクを含む短いフッターを追加します。デフォルトでオンになっています。

フォローアップメールは、シーケンス内のそれまでのメールと同じスレッドで、返信として送信されます。

**テンプレートからメールを作成**ステップを追加すると、Connektはテンプレートの名前、件名、メッセージ、署名の設定をステップにコピーします。テンプレートの添付ファイルは、保存時にコピーされます。その後ステップを変更しても、テンプレートは変更されません。

### 手動ステップ [#manual-steps]

手動ステップには、**ステップ名**、**待機期間（日）**、**メッセージ**があります。手動ステップが実行されると、Connektは次の処理を行います。

1. シーケンスの担当者である自分に割り当てられたタスクを作成します。タスクは候補者にリンクされ、トークンが置き換えられたメッセージが含まれます。
2. すぐに自分に通知を送信します。
3. 候補者を次のステップに進めます。タスクの完了は待ちません。

これらのタスクは、[タスク](/ja/tasks/managing-tasks)ページで確認できます。

<Warning>
  ConnektがLinkedInで代理送信することはありません。手動のLinkedInステップは、タスクを作成するだけです。メッセージやつながり申請は、自分で送信してください。
</Warning>

### 待機ステップ [#wait-steps]

**待機（日数）**を設定すると、次のステップの前にシーケンスを一時停止します。

### 条件ステップ [#condition-steps]

**候補者が次の条件を満たす場合のみ続行…**で、条件を選択します。

- **開封済み・未返信**
- **リンクをクリック済み**
- **未開封**

候補者が条件を満たす場合（**はい**）、次のステップに進みます。満たさない場合（**いいえ**）、その候補者のシーケンスは終了します。

条件は、その前にある直近のメールステップを確認します。条件の前にメールステップがない場合は、常に続行します。

<Tip>
  Connektは、シーケンスのメールの開封とリンクのクリックを追跡します。一部のメールアプリでは開封の追跡がブロックされるため、開封数は目安として扱ってください。
</Tip>

## パーソナライズ用トークン [#personalization-tokens]

トークンは、メールの送信時に各候補者の情報に置き換えられます。ステップエディターでトークンボタンをクリックして挿入するか、二重の波括弧で囲んで入力します。

| ボタン | トークン | 置き換えられる情報 |
|---|---|---|
| **名** | `{{first_name}}` | 候補者の名 |
| **姓** | `{{last_name}}` | 候補者の姓 |
| **現在の勤務先** | `{{company}}` | 候補者の現在の勤務先 |
| **現在の役職** | `{{title}}` | 候補者の現在の役職 |
| **募集職種** | `{{role}}` | プロジェクトに紐づく求人の職種名 |
| **所在地** | `{{location}}` | 候補者の市区町村 |
| **リクルーター名** | `{{recruiter_name}}` | 自分の名前 |
| **採用企業** | `{{job_company}}` | プロジェクトに紐づく求人の企業 |
| **勤務地** | `{{job_location}}` | プロジェクトに紐づく求人の市区町村と国、または「リモート」 |

**募集職種**、**採用企業**、**勤務地**は、候補者の登録元のプロジェクトに紐づく求人から取得されます。プロジェクトに求人がない場合、これらのトークンは空欄になります。

<Warning>
  候補者のレコードに値がない場合、トークンは空欄になります。登録前に、メールで使用する情報が候補者のレコードに揃っていることを確認してください。
</Warning>

## 配信スケジュールを設定する [#set-the-delivery-schedule]

ビルダーのヘッダーにあるスケジュールボタンには、**5日間、9:00am–6:00pm**のように、メールを送信できる時間帯が表示されます。新しいシーケンスでは、自分のタイムゾーンで月曜日から金曜日の9:00amから6:00pmが使用されます。

ボタンをクリックすると、次の設定を変更できます。

- **タイムゾーン**：スケジュールで使用するタイムゾーンです。タイムゾーンが設定されていない場合、スケジュールは適用されず、ステップはいつでも実行されます。
- **日数**：ステップを実行できる曜日です。曜日を選択しない場合は、毎日実行できます。
- **開始時刻**と**終了時刻**：ステップを実行できる時間帯です。

**保存**をクリックして変更を適用します。

待機期間には、実行が許可されている曜日のみがカウントされます。たとえば、月曜日から金曜日を選択した場合、金曜日から2日間の待機を設定すると、火曜日に実行されます。Connektは15分ごとにステップを処理するため、予定時刻から最大15分後にステップが実行されることがあります。

## 候補者を登録する [#enroll-candidates]

<Steps>
  <Step title="登録ダイアログを開く">
    シーケンスビルダーで、**登録**をクリックします。
  </Step>
  <Step title="プロジェクトを選択する">
    **プロジェクトを絞り込み...**でプロジェクトを探して選択します。別のプロジェクトを選ぶには、**プロジェクトを変更**をクリックします。
  </Step>
  <Step title="候補者を選択する">
    メールアドレスがある候補者は、すべて選択されています。不要な候補者の選択を解除するか、**すべて選択**と**すべて選択解除**を使います。
  </Step>
  <Step title="登録する">
    **登録**をクリックします。Connektに、登録された候補者の数と、すでにシーケンスに登録されているためスキップされた候補者の数が表示されます。
  </Step>
</Steps>

- メールアドレスがない候補者は選択できません。候補者の横にある連絡先エンリッチメントのアイコンをクリックして、個人用メールアドレスを検索します。[連絡先情報のエンリッチメント](/ja/candidates/enriching-contact-details)をご覧ください。
- 候補者への送信では、Connektは個人用メールアドレスを優先し、次に勤務先のメールアドレスを使用します。
- 同じ候補者を同じシーケンスに登録できるのは1回だけです。
- シーケンスが下書きまたは一時停止中でも、候補者を登録できます。有効化するまで、何も送信されません。

<Note>
  一度に登録できる候補者は最大500人です。登録ダイアログには、プロジェクトの候補者が最大500人表示されます。
</Note>

## 登録ステータス [#enrollment-statuses]

登録された各候補者にはステータスがあります。[受信トレイ](/ja/outreach/using-the-inbox)で候補者との会話を開くと確認できます。

| ステータス | 意味 |
|---|---|
| **配信中** | 候補者のシーケンスが進行中です。 |
| **完了** | 候補者がシーケンスの最後まで到達しました。 |
| **返信あり** | 候補者が返信しました。残りのステップはキャンセルされました。 |
| **配信停止** | 候補者が配信停止リンクをクリックしました。残りのステップはキャンセルされました。 |
| **配信エラー** | メールを配信できませんでした。残りのステップはキャンセルされました。 |
| **終了（条件達成）** | 候補者のシーケンスが終了しました。条件を満たさない場合や、メールアドレスがないなどの理由でメールを送信できない場合に、このステータスになります。 |

## 返信、配信エラー、配信停止 [#replies-bounces-and-opt-outs]

- **返信があるとシーケンスが停止します。**候補者がシーケンスのメールに返信すると、Connektはステータスを**返信あり**にし、残りのステップをキャンセルします。返信は[受信トレイ](/ja/outreach/using-the-inbox)に表示されます。
- **配信エラーが発生するとシーケンスが停止します。**メールが配信エラーになると、候補者のステータスは**配信エラー**になり、それ以降のステップは実行されません。
- **配信停止は1つのシーケンスに適用されます。**候補者が配信停止リンクをクリックすると、そのシーケンスからのメールは届かなくなります。他のシーケンスからは削除されません。

## 1日の送信上限 [#daily-sending-limit]

各ユーザーは、シーケンスのメールを1日あたり最大400通送信できます。上限に達すると、残りのメールは待機し、翌日に上限がリセットされてから送信されます。

## 実行中のシーケンスを編集する [#edit-a-running-sequence]

シーケンスが有効な状態でも、ステップを変更して**保存**をクリックできます。変更は、まだ実行されていないステップに適用されます。

<Warning>
  登録済み候補者の処理履歴があるステップは削除できません。Connektに「登録済み候補者の処理履歴があるステップは削除できません。先に該当する候補者のシーケンスを停止するか、完了してください。」と表示されます。
</Warning>

## シーケンスを複製または削除する [#duplicate-or-delete-a-sequence]

- シーケンスをコピーするには、その行の**⋯ → 複製**をクリックします。コピーは名前に「(copy)」が付いた**下書き**になり、ステップとスケジュールは同じです。登録済みの候補者はいません。
- シーケンスを削除するには、**⋯ → 削除**をクリックし、確認します。

<Warning>
  削除できるのは、下書きまたはアーカイブ済みのシーケンスのみです。一度有効化したシーケンスは、削除ではなく一時停止してください。削除は取り消せません。
</Warning>
