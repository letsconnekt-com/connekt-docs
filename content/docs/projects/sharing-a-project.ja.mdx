安全なリンクを使って、プロジェクトをクライアントと共有できます。Connektがクライアントにリンクをメールで送信します。クライアントはConnektのアカウントがなくても、ブラウザーでショートリストを開けます。候補者を確認し、各候補者について判断を伝えたり、フィードバックを残したり、履歴書を表示したり、リストをCSVとしてエクスポートしたりできます。

## 共有前の確認事項 [#before-you-share]

- **プロジェクトを共有できるのは作成者のみです。** **編集可能**のアクセス権を持つチームメンバーも共有ダイアログを開けますが、共有を実行しても失敗します。
- **プロジェクトは企業に紐付ける必要があります。** 紐付けられていない場合は、共有ダイアログで企業を選択します。

## プロジェクトを共有する [#share-a-project]

<Steps>
  <Step title="共有ダイアログを開く">
    プロジェクトを開き、ヘッダーの**⋯**メニューから**共有**をクリックします。**設定**タブで**企業と共有**をクリックすることもできます。**企業と共有**ダイアログが開きます。
  </Step>
  <Step title="企業を選択する">
    **企業を選択**で、**企業**を確認します。別の企業を選ぶには、**変更**をクリックします。**求人（任意）**も選択できます。選択内容は、リンクの送信時にプロジェクトに保存されます。
  </Step>
  <Step title="クライアントに表示する情報を選択する">
    **クライアントに表示される情報**で、各項目のオン・オフを切り替えます。詳しくは下の表を参照してください。
  </Step>
  <Step title="クライアントの情報を入力する">
    **アクセスリンクを生成**で、**クライアント名（任意）**とクライアントの**企業のメールアドレス**を入力します。
  </Step>
  <Step title="有効期限を設定する">
    **リンクの有効期限**で、**7日間**、**14日間**、**30日間**、**60日間**、**90日間**、**無期限**のいずれかを選択します。初期設定は**30日間**です。
  </Step>
  <Step title="「生成して送信」をクリックする">
    Connektがクライアントにリンクをメールで送信し、クリップボードにもコピーします。リンクはダイアログにも表示されるため、再度コピーできます。
  </Step>
</Steps>

メールには、プロジェクト名、リンク、有効期限、あなたの名前が記載されます。プロジェクトを共有すると、**プロジェクト**一覧とプロジェクト上に**クライアントと共有済み**バッジが表示されます。

## クライアントに表示する情報を選択する [#choose-what-the-client-can-see]

7つの項目はすべて初期設定でオンになっています。切り替えるとすぐに保存され、そのプロジェクトのすべてのクライアント用リンクに適用されます。

| 項目 | クライアントに表示される情報 |
|---|---|
| **連絡先情報** | メールアドレス、携帯電話番号、LinkedInのURL |
| **年収** | 現在の年収と通貨 |
| **履歴書** | 候補者の履歴書を表示するボタン |
| **クライアントのフィードバック** | クライアントがコメントを投稿できる、候補者ごとのフィードバックスレッド |
| **ステータス** | プロジェクト内での各候補者の選考段階 |
| **ステータス履歴** | ステータスの変更とクライアントの過去の判断を時系列で表示した履歴 |
| **最終更新** | 各候補者についてあなたが記録した更新ログ |

<Warning>
  連絡先情報と年収は初期設定で共有されます。クライアントに表示しない場合は、**生成して送信**をクリックする前に**連絡先情報**と**年収**をオフにしてください。
</Warning>

<Warning>
  プロジェクト内でチームが候補者に追加した**メモ**は、常に**採用担当者のメモ**としてクライアントに表示されます。非表示にする設定はありません。クライアントに読まれてもよい内容だけを記入してください。
</Warning>

## メールアドレスごとに1つのリンク [#one-link-per-email-address]

メールアドレスごとに専用のリンクが発行されます。クライアント側の複数の相手に共有するには、メールアドレスごとにリンクを生成します。

すでにリンクがあるメールアドレスに再度共有すると、Connektが新しいリンクを送信し、古いリンクは使えなくなります。有効期限は新しく選択した期間にリセットされます。アクセス権を取り消していた場合も、これによりアクセスが復元されます。

## 有効なリンクを管理する [#manage-active-links]

取り消されていないリンクはすべて、共有ダイアログの**有効なアクセス**に表示されます。各項目には、次の情報が表示されます。

- クライアントの名前とメールアドレス
- **共有者**と共有日
- 有効期限、または**有効期限なし**
- クライアントの閲覧回数、または**未閲覧**
- **期限切れ**バッジ、または残り期間が7日未満の場合に残り日数を示すバッジ

<AccordionGroup>
  <Accordion title="有効期限またはクライアント名を変更する">
    カレンダーアイコンをクリックして**アクセス権を編集**を開きます。**クライアント名**を更新するか、**有効期限**で新しい期間を選択し、**変更を保存**をクリックします。クライアントは引き続き同じリンクを使用できます。新しい有効期限は今日から数えます。
  </Accordion>
  <Accordion title="リンクを再度コピーする">
    コピーアイコンをクリックします。期限切れのリンクはコピーできません。先に有効期限を更新してください。
  </Accordion>
  <Accordion title="アクセス権を取り消す">
    ごみ箱アイコンをクリックし、**はい**をクリックします。リンクはすぐに使えなくなります。
  </Accordion>
</AccordionGroup>

リンクの変更、取り消し、作成ができるのは、プロジェクトの作成者のみです。

## クライアント側の表示 [#what-your-client-sees]

クライアントがリンクを開くと、プロジェクト名、企業、説明、アクセスの有効期限が表示されます。その下の**候補者ショートリスト**には、各候補者と現在の役職・勤務先企業が表示されます。それ以外の列は、オンにした項目によって異なります。

クライアントには、クライアント向けの選考段階名が表示されます。たとえば、**不採用**は**選考対象外**、**返信なし**は**返信がありませんでした**、**候補者による辞退**は**候補者の意向により見送り**と表示されます。

クライアントは次の操作ができます。

<CardGroup cols={2}>
  <Card title="判断を伝える" icon="circle-check">
    **今後の対応**で、**選考を継続**、**保留に変更**、**選考を終了**のいずれかを選択します。必要に応じてメモを追加し、**送信**をクリックします。
  </Card>
  <Card title="フィードバックを残す" icon="pen-nib">
    **クライアントのフィードバック**スレッドで候補者へのコメントを投稿します。**クライアントのフィードバック**がオンになっている必要があります。
  </Card>
  <Card title="履歴書を表示する" icon="file">
    **履歴書**列の**表示**をクリックします。**履歴書**がオンになっている必要があります。
  </Card>
  <Card title="CSVをエクスポートする" icon="file-lines">
    **CSVをエクスポート**をクリックして、ショートリストをダウンロードします。
  </Card>
</CardGroup>

候補者をクリックすると、詳細パネルが開きます。設定に応じて、連絡先情報、報酬、フィードバック、更新ログ、リクルーターのメモ、ステータス履歴、クライアントの判断履歴が表示されます。

<Note>
  **表示**ボタンをクリックすると、候補者のレコードに最後にアップロードされたファイルが開きます。履歴書の後に別の書類をアップロードすると、クライアントには履歴書ではなく、その最新の書類が表示されます。
</Note>

<Info>
  CSVには、各候補者の名前、現在の役職、勤務先企業が含まれます。連絡先情報、年収、選考段階は、それぞれの項目がオンの場合にのみ含まれます。**備考**列には、リクルーターの最新のメモが入ります。
</Info>

クライアントの判断は、候補者の現在の選考段階に適用されます。プロジェクト内で候補者のステータスを変更すると、判断がリセットされ、クライアントが再度判断できるようになります。

## クライアントのフィードバックを確認する [#see-your-clients-feedback]

クライアントの操作は、プロジェクトの**候補者**タブに表示されます。

- **クライアントステータス**には、最新の判断が**選考継続**、**保留**、**選考終了**、**保留中**のいずれかで表示されます。
- **クライアントのフィードバック**を開くと、クライアントのコメントが表示されます。閲覧はできますが、そこで返信することはできません。
- **履歴**には、各判断が**クライアントによる**というラベル付きで表示されます。

プロジェクトの作成者には、次の通知も届きます。

- クライアントが判断を送信すると、**クライアントのフィードバック：…**が届きます。この通知はメールでも届きます。
- クライアントがコメントを投稿すると、**クライアントからの新しいフィードバック**が届きます。

クライアントの判断によって、候補者のステータスや推薦が変更されることはありません。必要なタイミングで、ご自身でステータスを更新してください。[通知設定](/ja/integrations/notification-preferences)を参照してください。

## リンクが使えなくなる場合 [#when-a-link-stops-working]

リンクは、有効期限が切れた場合、アクセス権を取り消した場合、または同じメールアドレスに新しいリンクを送信した場合に使えなくなります。

クライアントが使えなくなったリンクを開くと、**プロジェクトを読み込めませんでした**と、「アクセストークンの有効期限が切れています」や「アクセス権が取り消されています」などの理由が表示されます。再びアクセスできるようにするには、**有効なアクセス**でリンクの有効期限を更新するか、そのメールアドレスにプロジェクトを再度共有します。
