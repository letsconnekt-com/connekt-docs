要約テンプレートは、ミーティングをどのように要約するかをConnektに指示するものです。録音を開始するときに選択し、ミーティング後でもテンプレートを切り替えられます。質問を含むテンプレートは、リアルタイムの**ヒアリングチェックリスト**と**質問の網羅度**レポートにも使用されます。

## テンプレートの場所 [#where-to-find-templates]

**設定 → テンプレート**に移動します。使用できるすべてのテンプレートが一覧に表示されます。

- **定義済み**テンプレートはConnektに標準で用意されています。編集や削除はできません。
- カスタムテンプレートには、閲覧できるユーザーの範囲に応じて**組織**または**非公開**と表示されます。

各ミーティングの**AI要約**カードにあるテンプレートのドロップダウンから、**新規テンプレート**をクリックすることもできます。

## 標準テンプレート [#built-in-templates]

| テンプレート | 種類 | 用途 |
| --- | --- | --- |
| **一般的なメモ** | プロンプト | 概要、アクション項目、議題、重要な詳細を含む全体的な要約です。デフォルトのテンプレートです。 |
| **重要なポイント** | プロンプト | 主な成果と次のステップを簡潔にまとめます。 |
| **技術的な打ち合わせ** | プロンプト | 技術的な決定事項、未解決の質問、アクション項目をまとめます。 |
| **質疑応答** | 質問 | 実際に行われた質問、その回答、未回答の内容をまとめます。 |
| **スクリーニング面接** | 質問 | 候補者のスクリーニングに使用します。経験、転職動機、現在と希望の報酬、退職予告期間、他社の面接状況、次のステップをまとめます。 |
| **求人要件のヒアリング** | 質問 | クライアントから新しい求人の要件を聞き取る際に使用します。職種名、年収範囲、募集人数、スキル、勤務地、採用スケジュールをまとめます。 |
| **企業紹介の打ち合わせ** | 質問 | 見込みクライアントとの初回の打ち合わせに使用します。事業内容、主なコンタクト、採用ニーズ、採用プロセスをまとめます。 |
| **営業メモ** | 質問 | ビジネス上のニーズ、予算とスケジュール、関係者、懸念や反対意見、次のステップをまとめます。 |
| **顧客との状況確認** | 質問 | クライアントの状況や心情、懸念、フィードバック、フォローアップ事項をまとめます。 |

**スクリーニング面接**、**求人要件のヒアリング**、**企業紹介の打ち合わせ**の一部の質問は、候補者の現在の基本年収や求人の年収など、レコードのフィールドに紐付けられています。

## テンプレートを作成する [#create-a-template]

<Steps>
  <Step title="新規テンプレートを作成する">
    **設定 → テンプレート**に移動し、**新規テンプレート**をクリックします。
  </Step>
  <Step title="名前を付ける">
    **名前**を入力します。例：「営業電話の振り返り」。
  </Step>
  <Step title="種類を選択する">
    **カスタムプロンプト**または**カスタム質問**を選択します。テンプレートの作成後は種類を変更できません。
  </Step>
  <Step title="プロンプトまたは質問を入力する">
    **カスタムプロンプト**の場合は、**プロンプト**に指示を入力します。**カスタム質問**の場合は、質問を1つずつ入力し、追加するには**質問を追加**をクリックします。
  </Step>
  <Step title="公開範囲を選択する">
    **公開範囲**で、**組織内公開 — チーム全員が閲覧可能**または**非公開 — 自分のみ閲覧可能**を選択します。
  </Step>
  <Step title="保存する">
    **テンプレートを作成**をクリックします。作成したテンプレートは、Connekt Notetakerのポップアップとすべてのミーティングで使用できるようになります。
  </Step>
</Steps>

## カスタムプロンプトとカスタム質問の比較 [#custom-prompt-or-custom-questions]

| | **カスタムプロンプト** | **カスタム質問** |
| --- | --- | --- |
| 入力する内容 | 要約への指示です。例：「予算、スケジュール、挙げられた懸念や反対意見を中心に、この通話を要約してください。」 | 回答を得たい質問のリストです。 |
| 作成される内容 | 指示に沿った要約です。 | 各質問に回答する要約です。 |
| リアルタイムのチェックリスト | なし | あり（Stealthモード） |
| 質問の網羅度 | なし | あり |

カスタム質問テンプレートは、面接やヒアリングなど、毎回同じ項目を漏れなく確認したい場合に適しています。

## 質問をレコードのフィールドに紐付ける [#map-questions-to-record-fields]

**カスタム質問**テンプレートでは、各質問の回答をレコードのフィールドに入力できます。質問の横にある**フィールドに入力しますか？**でレコードの種類を選択し、**どのフィールドですか？**でフィールドを選択します。回答をフィールドに入力する必要がない場合は、**フィールドに入力しない**のままにします。

| レコードの種類 | 紐付け可能なフィールド |
| --- | --- |
| **候補者** | 希望年収（総額）、希望基本年収、希望賞与、希望株式報酬（年換算）、希望手当、現在の年収（総額）、現在の基本年収、現在の賞与、現在の株式報酬（年換算）、現在の手当、現在の勤務先、現在の役職、経験年数、生年月日 |
| **企業** | 業種 |
| **求人** | 職種名、年収下限、年収上限、募集人数、スキル |
| **コンタクト** | 役職 |

ミーティングを該当するレコードに紐付けると、これらのフィールドに入力するためのAIの提案として、回答が表示されることがあります。Connektが入力するのは空のフィールドのみです。詳しくは、[紐付けとAIアクション](/ja/meetings/linking-and-ai-actions)をご覧ください。

## テンプレートを編集・削除する [#edit-or-delete-a-template]

**設定 → テンプレート**で、鉛筆アイコンをクリックするとテンプレートを編集でき、ごみ箱アイコンをクリックすると削除できます。テンプレートを編集・削除できるのは、作成したユーザーのみです。

テンプレートを削除すると、今後の要約で使用するテンプレートの一覧から削除されます。
