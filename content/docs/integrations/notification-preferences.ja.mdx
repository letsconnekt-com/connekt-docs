Connektは、メンション、タスク、休暇、人材紹介業務の更新情報などを通知します。すべての通知はConnekt内に表示されます。その中から、スマートフォンのプッシュ通知やメールでも受け取るものを選べます。

## 通知の表示場所 [#where-notifications-appear]

- **ベルアイコン。** ベルアイコンをクリックすると、最新の通知を確認できます。**すべて**、**メンション**、**休暇**、**財務**、**ドキュメント**の各タブで絞り込むか、**すべて既読にする**をクリックします。
- **通知ページ。** サイドバーの**通知**をクリックするか、ベルアイコンを開いた画面の下部にある**すべての通知を表示**をクリックします。通知は**本日**、**昨日**、**それ以前**に分類されます。**すべて既読にする**をクリックすると、未読件数がゼロになります。
- **ブラウザー通知。** ブラウザーでConnektを開いている間は、新しい通知がアプリ内にポップアップ表示されます。ブラウザー通知を許可している場合は、デスクトップ通知としても表示されます。
- **プッシュ通知。** プッシュ通知はConnektのモバイルアプリに届きます。[モバイルアプリの使い方](/ja/mobile/using-the-mobile-app)をご覧ください。
- **メール。** メール通知はConnektアカウントのメールアドレスに届きます。

<Tip>
  **G**、**B**の順にキーを押すと、通知ページに移動できます。
</Tip>

<Note>
  Connektは各通知を発生時に送信します。日次や週次のダイジェスト配信はありません。
</Note>

## ブラウザー通知を許可する [#allow-browser-notifications]

Connektを初めて使うときは、画面の隅に**通知を有効化**というメッセージが表示されます。**許可**をクリックし、続いてブラウザーからの許可リクエストを承認します。

**今はしない**をクリックした場合や通知をブロックした場合は、ブラウザーのConnektのサイト設定で通知を有効にしてください。

## 通知方法を選ぶ [#choose-how-youre-notified]

<Tabs>
  <Tab title="Web">
    <Steps>
      <Step title="通知設定を開く">
        **設定 → 通知**に移動します。
      </Step>
      <Step title="通知をオンまたはオフにする">
        各通知の種類の横にあるスイッチを切り替えます。オフにすると、その種類のプッシュ通知とメール通知の両方が停止します。
      </Step>
      <Step title="通知チャネルを選ぶ">
        通知の種類がオンになっている状態で、**詳細を表示**をクリックします。**プッシュ通知**と**メール**をそれぞれオンまたはオフにします。通知の種類の下には、設定に応じて**プッシュ通知とメール**、**プッシュ通知のみ**、**メールのみ**と表示されます。
      </Step>
    </Steps>
  </Tab>
  <Tab title="モバイル">
    <Steps>
      <Step title="プロフィールを開く">
        **ホーム**タブでプロフィールの顔写真をタップします。
      </Step>
      <Step title="通知設定を開く">
        **通知**をタップします。
      </Step>
      <Step title="この端末でプッシュ通知を許可する">
        **プッシュ通知**をオンにして、スマートフォンでのプッシュ通知を許可します。
      </Step>
      <Step title="通知の種類とチャネルを選ぶ">
        各通知の種類の横にあるスイッチを切り替えます。**詳細を表示**をタップし、**プッシュ通知**、**メール**、またはその両方を選びます。
      </Step>
    </Steps>
  </Tab>
</Tabs>

変更はすぐに保存され、Webとモバイルの両方に適用されます。

<Info>
  通知をオフにしても、停止するのはプッシュ通知とメール通知だけです。ベルアイコンと通知ページには引き続き表示されます。
</Info>

## 通知の種類 [#notification-types]

すべての種類で、プッシュ通知は初期設定でオンになっています。メール通知は、下の表で「オン」と記載されているものだけが初期設定でオンになっています。

| グループ | 通知 | 通知されるタイミング | メールの初期設定 |
|---|---|---|---|
| マッチング | **新しい候補者が見つかりました** | 担当する求人に適している可能性のある候補者が見つかったときです。 | オフ |
| メンションとコメント | **ノート内でのメンション** | ノート内で自分が@メンションされたときです。 | オン |
| メンションとコメント | **コメント内でのメンション** | ノートのコメント内で自分が@メンションされたときです。 | オン |
| メンションとコメント | **コメント追加時** | フォロー中のノートに誰かがコメントしたときです。 | オン |
| タスク | **タスクの割り当て** | 自分にタスクが割り当てられたときです。 | オン |
| タスク | **タスクのリマインダー** | タスクの期限が近づいたとき、または期限を過ぎたときです。 | オフ |
| 休暇 | **休暇申請時** | チームメンバーが自分の承認を必要とする休暇申請を送信したときです。 | オフ |
| 休暇 | **休暇申請の承認** | 自分の休暇申請が承認されたときです。 | オフ |
| 休暇 | **休暇申請の却下** | 自分の休暇申請が却下されたときです。 | オフ |
| 人材紹介 | **候補者の推薦** | 自分が担当する候補者を他のユーザーが推薦したときです。 | オフ |
| 人材紹介 | **候補者の担当変更** | 候補者の担当者が自分に変更されたとき、または自分から他のユーザーに変更されたときです。 | オフ |
| 財務 | **請求書の支払期日になったとき** | 請求書の支払期日になったときです。 | オフ |
| 財務 | **支払期日になったとき** | 支払期日になったときです。 | オフ |
| 財務 | **支払期限超過** | 支払期限を過ぎたときです。 | オフ |
| 書類 | **書類の共有** | 自分に書類が共有されたときです。 | オン |
| システム | **システム通知** | 休暇残日数の更新など、システムに関する重要なお知らせがあるときです。 | オフ |

<Note>
  電子署名の署名状況やレビューの更新など、一部の通知は通知設定に表示されません。
</Note>

## トラブルシューティング [#troubleshooting]

<AccordionGroup>
  <Accordion title="スマートフォンにプッシュ通知が届かない">
    モバイルアプリの**プロフィール → 通知**で、**プッシュ通知**がオンになっていることを確認してください。次に、スマートフォンの設定でConnektの通知が許可されていることを確認してください。該当する通知の種類で**プッシュ通知**がオンになっていることも確認してください。
  </Accordion>
  <Accordion title="デスクトップ通知が届かない">
    デスクトップ通知は、ブラウザーでConnektを開いている間だけ表示されます。ブラウザーでConnektの通知が許可されていることを確認してください。
  </Accordion>
  <Accordion title="通知のメールが届かない">
    ほとんどの種類では、初期設定でメール通知がオフになっています。**設定 → 通知**に移動し、該当する種類の**詳細を表示**をクリックして、**メール**をオンにしてください。
  </Accordion>
  <Accordion title="通知をオフにしてもベルアイコンに表示される">
    これは正常な動作です。スイッチで切り替えられるのはプッシュ通知とメール通知だけです。すべての通知は、引き続きベルアイコンと通知ページに表示されます。
  </Accordion>
</AccordionGroup>

さらにサポートが必要な場合は、[サポートを受ける](/ja/getting-started/getting-help)をご覧ください。
