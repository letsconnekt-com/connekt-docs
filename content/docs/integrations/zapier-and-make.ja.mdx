description: "ワークスペースのZapier APIトークンを使ってConnektをZapierやMakeに接続し、Connektのイベントをきっかけに自動化を実行したり、レコードを作成したりします。"
---

ConnektをZapierやMakeに接続すると、Connektと他のツールを連携させて業務を自動化できます。候補者の新規登録や書類への署名など、Connektのイベントをきっかけに自動化を開始できます。自動化によってConnektに候補者、コンタクト、企業、求人を作成することもできます。どちらのサービスも、ワークスペースの**Zapier APIトークン**を使って接続します。

<Info>
  ZapierとMakeの利用には**Teamプラン以上**が必要です。[プランの比較](/ja/billing/plans-compared)をご覧ください。
</Info>

## トークンを管理できるユーザー [#who-can-manage-the-token]

スーパー管理者と管理者は、**設定 → APIキー**でトークンの有効化、コピー、リセットができます。ワークスペースにはトークンが1つあり、全員の自動化で同じトークンを使用します。

<Warning>
  トークンを使うと、ワークスペースのデータにアクセスできます。トークンは他の人に公開せず、ZapierまたはMake以外には貼り付けないでください。
</Warning>

## APIトークンを取得する [#get-your-api-token]

<Steps>
  <Step title="APIキーの設定を開く">
    **設定 → APIキー**に移動します。
  </Step>
  <Step title="トークンを有効にする">
    **APIトークンを有効化**をオンにします。Connektがトークンを作成し、ステータスが**APIトークンは有効です**に変わります。
  </Step>
  <Step title="トークンをコピーする">
    目のアイコンをクリックしてトークンを表示するか、コピーアイコンをクリックしてコピーします。
  </Step>
</Steps>

## ZapierやMakeで接続する [#connect-in-zapier-or-make]

<Steps>
  <Step title="自動化にConnektを追加する">
    ZapierではZapを、Makeではシナリオを作成します。トリガーまたはアクションのステップで、アプリとしてConnektを追加します。
  </Step>
  <Step title="Connektアカウントを接続する">
    Connektへの接続を求められたら、Zapier APIトークンを貼り付けます。ZapierとMakeの両方で同じトークンを使用します。
  </Step>
  <Step title="トリガーまたはアクションを選択する">
    以下のConnektのトリガーまたはアクションから1つを選び、ステップの設定を完了します。
  </Step>
  <Step title="自動化を有効にする">
    ステップをテストしてから、Zapまたはシナリオをオンにします。
  </Step>
</Steps>

## トリガー [#triggers]

トリガーは、Connektで何かが起きたときに自動化を開始します。

| レコード | トリガーとなるイベント |
|---|---|
| 候補者 | 作成、更新、削除 |
| 企業 | 作成、更新、削除 |
| コンタクト | 作成、更新、削除 |
| 求人 | 作成、更新、削除 |
| 推薦 | 作成、更新、削除 |
| 成約 | 作成、更新、削除、支払いステータスの更新 |
| メモ（すべてのレコード） | 作成、更新 |
| 候補者のメモ | 作成、更新、削除 |
| 企業のメモ | 作成、更新、削除 |
| コンタクトのメモ | 作成、更新、削除 |
| 書類（電子署名） | 作成、送信、署名、完了、キャンセル、有効期限切れ |
| 休暇 | 申請、更新、承認、却下、キャンセル |

## アクション [#actions]

アクションは、自動化によってConnektにレコードを作成します。

- 候補者を作成
- コンタクトを作成
- 企業を作成
- 求人を作成

## トークンをリセットする [#reset-the-token]

他の人がトークンを入手した可能性がある場合や、接続中のすべてのアプリからのアクセスを遮断したい場合は、トークンをリセットします。

<Steps>
  <Step title="APIキーの設定を開く">
    **設定 → APIキー**に移動します。
  </Step>
  <Step title="リセットする">
    **トークンをリセット**をクリックし、**続行**をクリックして確定します。
  </Step>
  <Step title="接続を更新する">
    新しいトークンをコピーします。Connektを使用しているZapierとMakeのすべての接続に貼り付けます。
  </Step>
</Steps>

<Warning>
  リセットすると、古いトークンは直ちに使えなくなります。Connektを使用するすべてのZapとシナリオは、新しいトークンを設定するまでアクセスできなくなります。
</Warning>

## トークンを無効にする [#turn-off-the-token]

すべての自動化を一時停止するには、**APIトークンを有効化**をオフにします。トークンが無効な間、接続済みのアプリはConnektにアクセスできず、既存のトリガーはイベントの送信を停止します。トークンを再び有効にしたら、再接続するか、Zapとシナリオをいったんオフにしてからオンにし、トリガーを再開します。

## トラブルシューティング [#troubleshooting]

<AccordionGroup>
  <Accordion title="設定にAPIキーが表示されない">
    **設定 → APIキー**が表示されるのは、Teamプラン以上を利用しているスーパー管理者と管理者のみです。管理者に問い合わせるか、[プランの比較](/ja/billing/plans-compared)をご覧ください。
  </Accordion>
  <Accordion title="ZapierやMakeに「APIアクセスにはTeamプラン以上が必要です」と表示される">
    ワークスペースはAPIアクセスに対応していないプランを利用しています。**設定 → プラン**でTeamまたはBusinessにアップグレードします。
  </Accordion>
  <Accordion title="ZapierやMakeに「APIキーが無効です」または「APIキーが必要です」と表示される">
    トークンがリセットされたか、無効になっているか、正しく貼り付けられていません。**APIトークンを有効化**がオンになっていることを確認し、現在のトークンをコピーして、ZapierまたはMakeでConnektを再接続します。
  </Accordion>
  <Accordion title="トリガーが作動しなくなった">
    トークンをリセットまたは無効化すると、既存のトリガーは停止します。現在のトークンでConnektを再接続し、Zapまたはシナリオをいったんオフにしてからオンにします。
  </Accordion>
  <Accordion title="トークンをコピーできない">
    トークンは有効になっている間のみコピーできます。**APIトークンを有効化**をオンにして、もう一度試します。
  </Accordion>
</AccordionGroup>

さらにサポートが必要な場合は、[ヘルプを利用する](/ja/getting-started/getting-help)をご覧ください。
