Bulk import loads records from CSV files into Connekt. Use it to move from another ATS or CRM, or to add a large batch of records at once. You upload a CSV, map its columns to Connekt fields, choose how to handle duplicates, and run the import.

To import resumes rather than spreadsheet data, use [resume upload](/candidates/adding-a-candidate#upload-resumes) instead.

## What you can import

| Record type | Field you must map | Match duplicates on | ZIP attachments |
|---|---|---|---|
| Candidates | Full name | Personal email, Work email, Full name or Mobile | Yes |
| Companies | Company name | Company name | Yes |
| Contacts | Full name | Work email, Personal email, Full name + company or Full name only | Yes |
| Jobs | Job name | Job name | Yes |
| Users | Email | Email or Display name | No |

<Warning>
  Imported users count toward your seats. If an import would add more active users than your plan has seats, those rows fail with a "Seat limit reached" message. Deactivate users or [add seats](/billing/adding-removing-seats) first.
</Warning>

## Where to import

There are two places to start an import:

- **Settings → Data Import/Export:** click **Import** on the **Import Data** card. You can import several record types in one run, including users. Only admins with system administration permission see this page.
- **A record list:** on **Candidates**, **Companies**, **Contacts** or **Jobs**, click the arrow next to **Add**, then click **Import CSV**. This imports one record type. Anyone who can create that type of record can use it.

## Run an import

<Steps>
  <Step title="Upload files">
    Upload a CSV file for each record type you're importing. Click **Download sample CSV** to get a template with the right columns.

    To import files such as CVs or contracts, also upload a ZIP. You can upload a ZIP per record type, or one **Shared attachments** ZIP for everything. Then click **Continue to field mapping**.
  </Step>
  <Step title="Map fields">
    Connekt matches your CSV columns to Connekt fields and uses AI to suggest the rest. The **Status** column shows how each column was mapped:

    - **Auto-matched** or **AI matched**: Connekt is confident in the match.
    - **AI suggested** with **Review**: check this suggestion before you continue.
    - **Mapped**: you chose the field yourself.
    - **Skipped**: the column won't be imported.

    You can change any mapping. The required field for each record type must be mapped before you can continue.
  </Step>
  <Step title="Set duplicate rules">
    Under **Match existing records on**, choose the field that identifies a record that's already in Connekt. Then choose what happens under **When a row already exists**:

    - Leave both options unselected to keep the existing record and skip the row. This is the default. Click **Default: keep existing** to go back to it.
    - **Overwrite** updates the existing record with the values from your file.
    - **Create new** adds the row as a new record, even though it matches.

    If rows in your own file share the same match key, they appear under **Conflicts inside your file**. Click **Resolve** on each one, pick the row to keep, and click **Keep selected row**. You must resolve every conflict before you continue.
  </Step>
  <Step title="Run the import">
    Check the row counts for each record type, then click **Start import**. You can close the import panel while it runs. The progress moves to a small panel in the corner of the screen.

    When the import finishes, Connekt emails you a summary with the number of rows processed, created, updated, skipped and failed.
  </Step>
</Steps>

<Info>
  After the import, Connekt updates the search index so the new records appear in search. This happens automatically and can take a few minutes for large files.
</Info>

## Limits

- **CSV only.** Save spreadsheets as `.csv` before you upload. Each CSV can be up to 20 MB.
- **ZIP files** can be up to 1 GB, and up to 500 MB once unzipped.
- **No error file.** Connekt doesn't produce a downloadable list of failed rows. Use the counts in the summary email to check the result.

## Import attachments with a ZIP

<Steps>
  <Step title="Add filenames to your CSV">
    Add a column that lists each record's files by name, for example `jane-doe-cv.pdf`. To attach several files to one record, separate the filenames with a comma, semicolon or pipe (`|`).
  </Step>
  <Step title="Zip the files">
    Put all the files into a ZIP. The filenames in the ZIP must match the names in your CSV.
  </Step>
  <Step title="Map the column">
    During field mapping, map the filename column to **Documents**.
  </Step>
</Steps>

## Tips for a clean import

<AccordionGroup>
  <Accordion title="Prepare your CSV">
    - Use a single header row with clear column names. This helps the AI mapping.
    - Remove merged cells, formulas and formatting before you export to CSV.
    - Include email addresses where you can. They make the most reliable match keys.
  </Accordion>
  <Accordion title="Choose the right match key">
    Email is the safest match key. Name-only matching can treat two different people with the same name as one record. Rows with an empty match field never match an existing record.
  </Accordion>
  <Accordion title="Re-import after a partial import">
    Keep the default duplicate rule (keep existing) so rows that already imported are skipped. Choose **Overwrite** only when you want your file to replace what's in Connekt.
  </Accordion>
</AccordionGroup>

## Export your data

You can also export your workspace data. On **Settings → Data Import/Export**, click **Export** on the **Export data** card. Connekt emails the export to you when it's ready. See [Exporting data](/advanced/exporting-data).
