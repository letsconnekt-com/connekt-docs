Connektアプリには、Web版と同じアカウントでログインします。このページでは、ログイン、2段階認証（2FA）、パスワード、スクリーンショットの防止、サインアウトについて説明します。Web版のアカウントセキュリティについては、[セキュリティと2FA](/ja/account/security-and-2fa)をご覧ください。

<Note>
  アプリには新規登録機能がありません。Web版でワークスペースを作成するか、招待を受けて作成した既存のConnektアカウントが必要です。
</Note>

## ログインする [#sign-in]

<Tabs>
  <Tab title="メールとパスワード">
    <Steps>
      <Step title="ログイン情報を入力する">
        アプリを開き、**メール**と**パスワード**を入力します。
      </Step>
      <Step title="ログインをタップする">
        **ログイン**をタップします。アカウントで2FAが有効になっている場合は、続けてコードの入力を求められます。
      </Step>
    </Steps>
  </Tab>
  <Tab title="Google">
    <Steps>
      <Step title="Googleで続行をタップする">
        ログイン画面で**Googleで続行**をタップします。
      </Step>
      <Step title="Googleアカウントを選択する">
        Connektのメールアドレスと一致するGoogleアカウントを選択します。アカウントで2FAが有効になっている場合は、続けてコードの入力を求められます。
      </Step>
    </Steps>

    Googleでログインできるのは、Connektアカウントがすでに存在するメールアドレスのみです。新しいアカウントは作成されません。
  </Tab>
</Tabs>

### 2FAコードを入力する [#enter-your-2fa-code]

2FAを有効にしている場合は、ログイン後に認証画面が表示されます。認証アプリを開き、Connektの6桁のコードを入力します。6桁すべてを入力すると自動的に認証されます。**認証**をタップすることもできます。

別のアカウントでログインしてしまった場合は、**ログインに戻る**をタップします。

## 忘れたパスワードをリセットする [#reset-a-forgotten-password]

<Steps>
  <Step title="パスワードのリセット画面を開く">
    ログイン画面で**パスワードをお忘れですか？**をタップします。
  </Step>
  <Step title="リンクをリクエストする">
    メールアドレスを入力し、**リセットリンクを送信**をタップします。アプリに**受信トレイを確認してください**と表示されます。メールが届くまでに1分ほどかかることがあります。
  </Step>
  <Step title="新しいパスワードを設定する">
    スマートフォンでメール内のリンクを開きます。新しいパスワードと確認用のパスワードを入力し、**パスワードを更新**をタップします。
  </Step>
</Steps>

<Tip>
  アプリで設定する新しいパスワードは、8文字以上である必要があります。
</Tip>

## パスワードを変更する [#change-your-password]

<Steps>
  <Step title="セキュリティを開く">
    **その他 → プロフィールを表示 → セキュリティ**に移動します。
  </Step>
  <Step title="パスワードを変更をタップする">
    **現在のパスワード**と8文字以上の**新しいパスワード**を入力し、**新しいパスワード（確認）**に同じ新しいパスワードをもう一度入力します。
  </Step>
  <Step title="保存する">
    **パスワードを更新**をタップします。サインアウトされ、新しいパスワードでの再ログインを求められる場合があります。
  </Step>
</Steps>

## 2段階認証を有効にする [#turn-on-two-factor-authentication]

2FAでは、ログインするたびにGoogle Authenticator、Authy、1Passwordなどの認証アプリのコードを求められます。**セキュリティ**画面では、**２段階認証**の横に**有効**または**無効**と表示されます。

<Steps>
  <Step title="2FAの設定を開く">
    **その他 → プロフィールを表示 → セキュリティ**に移動し、**２段階認証**をタップします。
  </Step>
  <Step title="設定を開始する">
    **認証アプリを設定**をタップします。
  </Step>
  <Step title="認証アプリにConnektを追加する">
    次のいずれかの方法を選択します。

    - このスマートフォンに認証アプリがある場合は、**認証アプリで開く**をタップします。
    - **または、この設定キーを手動で入力**の下に表示されるキーをコピーし、認証アプリに貼り付けます。
    - **別のデバイスで設定しますか？QRコードを表示**をタップし、別のデバイスでコードをスキャンします。
  </Step>
  <Step title="認証する">
    **次へ — コードを入力**をタップします。認証アプリの6桁のコードを入力し、**認証して有効化**をタップします。2FAが有効になると、**アカウントは保護されています**と表示されます。
  </Step>
</Steps>

### 2段階認証を無効にする [#turn-off-two-factor-authentication]

**その他 → プロフィールを表示 → セキュリティ → ２段階認証**に移動します。**2段階認証を無効化**をタップし、確認画面で**無効化**をタップします。

<Warning>
  2FAを無効にすると、アカウントに不正アクセスされるリスクが高まります。再設定する場合、またはワークスペースで2FAが不要な場合にのみ無効にしてください。
</Warning>

## スクリーンショットの防止 [#screenshot-protection]

スクリーンショットの防止機能は、スマートフォンでConnektのデータが撮影・録画されるのを防ぎます。有効になっている場合、アプリのスクリーンショットや画面録画は空白になります。これは正常な動作であり、スマートフォンの不具合ではありません。

- 組織全体の設定で、組織のすべてのメンバーに適用されます。
- **デフォルトで有効**になっています。
- 変更できるのはスーパー管理者と管理者のみです。

アプリで有効または無効にするには、**その他 → プロフィールを表示 → セキュリティ**に移動します。**組織のセキュリティ**にある**スクリーンショットの防止**スイッチを使用します。管理者は、Web版の**設定 → セキュリティ**でも変更できます。

<Info>
  サポートへの問い合わせにスクリーンショットが必要で、管理者権限がない場合は、管理者に保護を一時的に無効にするよう依頼してください。代わりにチャットで問題を説明することもできます。
</Info>

## サインアウトする [#sign-out]

**その他 → プロフィールを表示**に移動し、**サインアウト**をタップして、確認画面で**サインアウト**をタップします。

サインアウトの影響は、このデバイスにのみ適用されます。Webアプリや他のデバイスでは、ログインしたままになります。また、このデバイスでは、再度ログインするまでプッシュ通知を受信しなくなります。

## エラーメッセージ [#error-messages]

| メッセージ | 意味と対処方法 |
|---|---|
| メールアドレスとパスワードを入力してください。 | どちらかの項目が空欄です。両方を入力して、もう一度お試しください。 |
| このGoogleアドレスのアカウントが見つかりません。管理者にお問い合わせください。 | そのGoogleメールアドレスに対応するConnektアカウントがありません。招待を受けたメールアドレスでログインするか、管理者に招待を依頼してください。 |
| 認証アプリの6桁のコードを入力してください。 | 2FAコードの入力が完了していません。6桁すべてを入力してください。 |
| MFA認証要素が見つかりません。サポートにお問い合わせください。 | アカウントは2FAコードの入力を待っていますが、認証アプリが設定されていません。[サポートへの問い合わせ](/ja/getting-started/getting-help)からサポートにご連絡ください。 |
| ログイン処理がすでに進行中です。 | Googleのログイン画面がすでに開いています。ログインを完了するか画面を閉じてから、もう一度お試しください。 |
| パスワードは8文字以上にしてください。 | より長いパスワードを設定してください。 |
| パスワードが一致しません。 | 新しいパスワードと確認用のパスワードが異なっています。もう一度入力してください。 |
| パスワードが正しくないか、エラーが発生しました | 現在のパスワードが正しくないか、変更を保存できませんでした。現在のパスワードを確認して、もう一度お試しください。 |
| コードが無効です。認証アプリを確認して、もう一度お試しください。 | 2FAの設定中に入力したコードが正しくないか、有効期限が切れています。認証アプリの最新のコードを入力してください。 |

それでもログインできない場合は、[サポートへの問い合わせ](/ja/getting-started/getting-help)をご覧ください。
