Connektモバイルアプリを使うと、デスクを離れていても業務を続けられます。既存のConnektアカウントでサインインすると、Webアプリと同じワークスペースのデータが表示されます。外出先でも手早く操作できるよう、レコードの検索や編集、対面ミーティングの録音、書類への署名、タスクや休暇の管理に対応しています。ワークスペースの設定と管理は、引き続きWebアプリで行います。

## アプリを入手する [#get-the-app]

iOSアプリはApp Storeで公開されています。Androidアプリは近日公開予定です。

| プラットフォーム | 提供状況 | 動作要件 |
|---|---|---|
| iOS | [App StoreのConnekt CRM](https://apps.apple.com/app/connekt-crm/id6759556691) | iOS 15.1以降を搭載したiPhoneまたはiPad |
| Android | 近日公開予定 | — |

App Storeへのリンクは、Webアプリの**設定 → ダウンロードとガイド**にもあります。

<Note>
  アプリではアカウントやワークスペースを作成できません。先にWebで登録するか、管理者に招待を依頼してください。[チームを招待する](/ja/getting-started/inviting-your-team)を参照してください。
</Note>

## 画面構成 [#find-your-way-around]

画面下部のタブバーには、4つのタブがあります。

| タブ | 表示内容 |
|---|---|
| **ホーム** | あいさつ、目標の進捗、**週**・**月**・**四半期**・**年**ごとの指標が表示されます。ベルアイコンで通知を、アバターでプロフィールを開きます。 |
| **候補者** | 検索機能付きの候補者一覧が表示されます。 |
| **企業** | 検索機能付きの企業一覧が表示されます。 |
| **その他** | プロフィールカードと、その他の機能がグリッド形式で表示されます。 |

ほとんどの画面では、タブバーの上に丸い**AIに質問**ボタン（きらめきアイコン）が表示されます。このボタンでAI候補者検索を開きます。[モバイルでAI候補者検索を使う](/ja/mobile/ai-search)を参照してください。

**その他**のグリッドには、次の項目があります。

- **ミーティング**
- **タスク**
- **コンタクト**
- **求人**
- **電子署名**
- **商談**
- **成約**
- **休暇**
- **ヘルプとサポート**

<Info>
  表示される項目は、ロールとプランによって異なります。たとえば、**候補者**、**企業**、**コンタクト**、**求人**は、ロールに閲覧権限がある場合にのみ表示されます。**休暇**にはTeam以上のプランが必要です。**電子署名**は、ご利用のプランに含まれている場合にのみ表示されます。
</Info>

## アプリでできること [#what-you-can-do-in-the-app]

ほとんどの機能で、閲覧、作成、編集ができます。レコードの削除はWebアプリでのみ行えます。

| 機能 | できること |
|---|---|
| **候補者** | 検索、プロフィールの閲覧（**概要**、**推薦**、**成約**、**メモ**、**ドキュメント**）、候補者の追加と編集ができます。 |
| **企業** | 検索、企業の閲覧（**概要**、**メモ**、**ドキュメント**、**ニュース**）、企業の追加と編集ができます。 |
| **コンタクト** | コンタクトの検索、閲覧、追加、編集ができます。 |
| **求人** | 検索、求人とその推薦の閲覧、求人の作成と編集ができます。 |
| **メモと書類** | 候補者、企業、コンタクト、求人のメモを追加・編集し、コメントに返信し、書類をアップロードできます。 |
| **商談** | パイプラインを閲覧し、**ステータスを更新**で商談のステータスを変更できます。パイプラインの管理権限が必要です。 |
| **成約** | 成約とその詳細を閲覧できます。アプリでは成約の閲覧のみ可能です。 |
| **タスク** | タスクの作成、編集、完了、削除ができます。優先度、期限、リマインダー、担当者を設定し、タスクをレコードに紐付けられます。 |
| **休暇** | 休暇残日数の確認、休暇の申請、承認待ちの申請の取り消しができます。承認者には**承認**タブも表示されます。 |
| **ミーティング** | 対面ミーティングを録音し、要約、文字起こし、タスクを確認できます。[モバイルでミーティングを録音する](/ja/mobile/recording-meetings)を参照してください。 |
| **電子署名** | ファイル、写真、スキャンから書類を作成し、署名を依頼するために送信したり、署名したりできます。[モバイルで電子署名を使う](/ja/mobile/esign)を参照してください。 |

### 商談 [#deals]

**商談**にはパイプラインが表示されます。管理者とマネージャーは、自分のパイプラインとチームのパイプラインを切り替えられます。商談カードのステータスをタップして、**ステータスを更新**を開きます。新しいステータスを選択し、必要に応じてメモを追加します。**選考終了**を選択すると、候補者が進行中のパイプラインから除外されるため、**選考終了**での確認を求められます。

各ステータスの意味については、[推薦のステータス](/ja/submissions/submission-statuses)を参照してください。

### タスク [#tasks]

**タスク**にはタスク一覧が表示され、検索や、ステータス、優先度、担当者による絞り込みができます。**自分のタスク**と**すべてのタスク**を切り替えられます。タスクのチェックボックスをタップすると、完了にできます。タスクをタップすると編集でき、**タスクを削除**で削除できます。

タスクの詳細については、[タスクを管理する](/ja/tasks/managing-tasks)を参照してください。

### 休暇 [#time-off]

**休暇**の**概要**タブには取得可能な日数と今後の休暇が、**申請**タブには自分の申請が表示されます。**適用**をタップして休暇を申請します。休暇の種類と日付を選択し、10文字以上で理由を入力します。

ロールがスーパー管理者、管理者、オペレーション、マネージャーの場合は、**承認**タブも表示されます。このタブで承認待ちの申請を**承認**または**却下**できます。却下する場合は、任意で理由を追加できます。

休暇の詳細については、[休暇を申請する](/ja/time-off/requesting-time-off)と[休暇を承認する](/ja/time-off/approving-leave)を参照してください。

## Webアプリのみの機能 [#web-only]

次の機能はモバイルアプリにはありません。Webアプリを使用してください。

| 機能 | 利用場所・参照先 |
|---|---|
| 候補者、企業、コンタクト、求人の削除 | Webアプリ |
| 求人への候補者の推薦、成約の作成や編集 | [候補者を推薦する](/ja/submissions/submitting-a-candidate)、[成約を作成する](/ja/placements/creating-a-placement) |
| 詳細フィルターとブール検索 | [フィルターとブール検索](/ja/search/filters-and-boolean-search) |
| プロジェクトの閲覧と管理 | [プロジェクトを作成する](/ja/projects/creating-a-project) |
| メールの受信トレイ、シーケンス、テンプレート | [受信トレイを使う](/ja/outreach/using-the-inbox) |
| オンライン通話の録音（Google Meet、Zoom、Teams） | [ミーティングを録音する](/ja/meetings/recording-meetings) |
| 一括インポートとデータのエクスポート | [一括インポート](/ja/candidates/bulk-import)、[データをエクスポートする](/ja/advanced/exporting-data) |
| 請求、利用ユーザー数、ユーザー、ロール、権限 | [プランの比較](/ja/billing/plans-compared)、[ユーザーロール](/ja/team/user-roles) |
| 外部連携、カスタムフィールド、要約テンプレート、休暇ポリシー | Webアプリの**設定** |

<Note>
  アプリにオフラインモードはありません。データの読み込みと保存にはインターネット接続が必要です。一覧を下に引っ張ると更新され、Webでの変更が反映されます。
</Note>

## 通知 [#notifications]

サインイン後、Connektからの通知を許可するかどうかを端末が確認します。**許可**をタップすると、この端末でプッシュ通知を受け取れます。

通知する内容を変更するには、**その他 → プロフィールを表示 → 通知**を開きます。

1. **プッシュ通知**スイッチで、この端末のプッシュ通知をオンにします。最初の確認で許可しなかった場合は、このスイッチで端末の設定が開くので、そこで通知を許可します。
2. 各通知の種類の横にあるメインスイッチで、オンとオフを切り替えます。
3. 通知の種類の**詳細を表示**をタップし、**プッシュ通知**、**メール**、または両方を選択します。

通知の種類をオフにすると、その種類のプッシュ通知とメール通知の両方が停止します。**ホーム**のベルアイコンから開く通知トレイには、引き続き表示されます。

ここでの選択は、Webに表示される通知設定と共通です。[通知設定](/ja/integrations/notification-preferences)を参照してください。

## プロフィール [#your-profile]

**その他 → プロフィールを表示**を開くか、**ホーム**のアバターをタップします。プロフィールでは、次の操作ができます。

- 顔写真をタップして、新しい顔写真をアップロードします。
- **プロフィールを編集**をタップして、氏名、携帯電話番号、役職、国、通貨を変更します。アプリではメールアドレスを変更できません。
- **通知**を開いて、通知設定を管理します。
- **セキュリティ**を開いて、パスワードの変更や2段階認証の管理を行います。管理者はスクリーンショット保護も管理できます。[モバイルでのサインインとセキュリティ](/ja/mobile/signing-in-and-security)を参照してください。
- **サインアウト**をタップして、この端末からサインアウトします。

### 外観 [#appearance]

**外観**で、**ライト**、**ダーク**、**システム**から選択します。**システム**は、端末のライトモードまたはダークモードの設定に従います。

## サポートを利用する [#get-help]

**その他 → ヘルプとサポート**を開くと、アプリからConnektチームとチャットできます。その他のお問い合わせ方法については、[サポートを利用する](/ja/getting-started/getting-help)を参照してください。
