**設定 → 項目設定**では、レコードの項目を管理します。在留資格や契約区分など、Connektで標準では管理していないデータを記録するためのカスタム項目を追加できます。標準のシステム項目を非表示や必須に設定したり、項目が属するセクションの名前や順序を変更したりすることもできます。

<Note>
  項目設定には、**システム管理**権限が必要です。スーパー管理者と管理者には、デフォルトでこの権限が付与されています。
</Note>

## レコードの種類を選ぶ [#choose-a-record-type]

1. **設定 → 項目設定**に移動します。
2. 画面上部でレコードの種類を選択します。**候補者**、**企業**、**コンタクト**、**求人**、**成約**から選べます。

このページには、選択したレコードの種類のシステム項目がセクション別に表示され、カスタム項目も表示されます。**項目を検索...**を使うと、目的の項目をすぐに見つけられます。

## カスタム項目を作成する [#create-a-custom-field]

<Steps>
  <Step title="フォームを開く">
    **カスタム項目を追加**をクリックします。
  </Step>
  <Step title="ラベルを入力する">
    フォームに表示する名前を100文字以内で入力します。たとえば、「在留資格」と入力します。
  </Step>
  <Step title="項目の種類を選ぶ">
    下記の15種類から選択します。
  </Step>
  <Step title="セクションを選ぶ">
    項目を表示するセクションを選択するか、新しいセクションを作成します。
  </Step>
  <Step title="項目の種類に応じた詳細を設定する">
    項目の種類に応じて、プレースホルダー、プルダウンや複数選択の選択肢、関連付け先のモジュールを設定します。デフォルト値も設定できます。
  </Step>
  <Step title="オプションを設定する">
    レコードを保存する前に入力を必須にする場合は、**必須項目**をオンにします。Ask AIでこの項目を使用できるようにする場合は、**この項目をAI検索・チャットに表示**をオンのままにします。
  </Step>
  <Step title="保存する">
    **フィールドを作成**をクリックします。選択したレコードの種類ですぐに項目を使用できるようになります。
  </Step>
</Steps>

### 項目の種類 [#field-types]

| 種類 | 用途 |
|---|---|
| **テキスト** | 短い1行のテキスト |
| **テキストエリア** | 長いプレーンテキスト |
| **リッチテキスト** | 書式付きテキスト |
| **数値** | 数値 |
| **通貨** | 金額 |
| **URL** | Webリンク |
| **メール** | メールアドレス |
| **電話番号** | 電話番号 |
| **日付** | 日付 |
| **日時** | 時刻を含む日付 |
| **プルダウン** | 設定したリストから1つを選択 |
| **複数選択** | 設定したリストから複数を選択 |
| **トグル** | はい／いいえの値 |
| **ファイル** | 添付ファイル |
| **関連付け** | 別のモジュールのレコードへのリンク。対象は**候補者**、**企業**、**コンタクト**、**求人**、**成約**、**ユーザー**、**チームメンバー**です。 |

<Warning>
  ワークスペースで有効にできるカスタム項目は、すべてのレコードの種類を合わせて最大50個です。上限に達すると、**カスタム項目を追加**は無効になります。不要なカスタム項目を削除すると、新しい項目を追加できるようになります。非表示の項目も上限にカウントされます。
</Warning>

ワークスペースを上限の低いプランに変更しても、既存のカスタム項目は引き続き機能します。項目数が上限を下回るまでは、新しい項目を作成できません。

## カスタム項目を管理する [#manage-custom-fields]

カスタム項目の**⋯**メニューを開くと、次の操作ができます。

- **フィールドを編集**
- **必須に変更**または**任意に変更**
- **フォームで非表示**または**フォームに表示**
- **拡張機能で非表示**または**拡張機能で表示**で、ConnektのChrome拡張機能に項目を表示するかどうかを設定
- **フィールドを削除**

行をドラッグすると、フォーム上の項目の表示順を変更できます。

カスタム項目を削除しても既存の値は保持されますが、項目はフォームに表示されなくなります。

## カスタム項目の表示場所 [#where-custom-fields-appear]

カスタム項目は、作成・編集フォームとレコードの詳細ページに表示されます。候補者、企業、コンタクト、求人では、テーブルの列として追加することもできます。[表示する列を選ぶ](/ja/search/filters-and-boolean-search#choose-which-columns-you-see)を参照してください。

**拡張機能で表示**をオンにすると、[Chrome拡張機能](/ja/integrations/chrome-extension)にも項目が表示されます。

## システム項目を設定する [#configure-system-fields]

システム項目は、**勤務先メールアドレス**、**現在の役職**、**登録経路**などの標準項目です。削除はできませんが、動作を変更できます。

- **項目を必須にする：**項目の行にある**必須**スイッチをオンにします。
- **項目を非表示にする：**目のアイコンをクリックすると、作成・編集フォームで非表示になります。
- **拡張機能で表示・非表示を切り替える：**行にある拡張機能のアイコンを使います。

候補者の**名**と**姓**、求人の**掲載タイトル**など、一部の項目には**システム必須項目**と表示されます。これらの項目を非表示にしたり、変更したりすることはできません。

## セクションの名前と順序を変更する [#rename-and-reorder-sections]

項目はセクションごとにまとめられています。たとえば、候補者には**個人情報**や**職務情報**などのセクションがあります。

- **セクションの名前を変更する：**セクション名の横にある鉛筆アイコンをクリックし、新しい名前を入力して確定します。
- **セクション全体を非表示にする：**セクション見出しの**表示**スイッチをオフにします。
- **セクションを並べ替える：**セクション見出しを新しい位置にドラッグします。カスタムセクションをシステムセクションの間にドラッグすることもできます。

## レイアウトをリセットする [#reset-the-layout]

レコードの種類に加えた変更を元に戻すには、**表示順を初期状態に戻す**をクリックし、次に**リセット**をクリックします。

非表示の項目、必須設定、セクション名、項目の順序が、そのレコードの種類のデフォルトに戻ります。カスタム項目には影響しません。
