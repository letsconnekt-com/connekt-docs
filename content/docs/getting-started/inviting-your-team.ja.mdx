**設定 → ユーザー管理**からチームメンバーを1人ずつ追加します。各メンバーには、ログインリンク、メールアドレス、設定した仮パスワードが記載されたメールが届きます。

デフォルトでは、管理者と業務状況の役割を持つユーザーが他のユーザーを招待できます。招待する人数分の利用ユーザー枠に空きが必要です。無料トライアル中はワークスペースの利用ユーザー数が1人に限られるため、チームメンバーを招待するには先に有料プランを契約してください。[無料トライアル](/ja/getting-started/free-trial)をご覧ください。

## チームメンバーを招待する [#invite-a-team-member]

<Steps>
  <Step title="ユーザー管理を開く">
    **設定 → ユーザー管理**に移動します。
  </Step>
  <Step title="ユーザーを招待をクリックする">
    **ユーザーを招待**をクリックして、招待フォームを開きます。
  </Step>
  <Step title="メンバーの情報を入力する">
    必須項目の**メールアドレス**、**名**、**姓**、**仮パスワード**、**役割**、**通貨**、**雇用形態**を入力します。**携帯電話番号**、**役職**、**地域**、**オフィス**、**チーム**も追加できます。

    **入社日**には、デフォルトで今日の日付が設定されます。すでに在籍しているメンバーの場合は、実際の入社日に変更します。Connektはこの日付を休暇の計算に使用します。
  </Step>
  <Step title="招待を送信する">
    **招待を送信**をクリックします。新しいユーザーに招待メールがすぐに届きます。
  </Step>
</Steps>

<Tip>
  招待メールには、初回サインイン後にパスワードを変更するよう案内が記載されています。パスワードは**設定 → セキュリティ**から変更できます。[セキュリティと2段階認証](/ja/account/security-and-2fa)をご覧ください。
</Tip>

## 役割を選択する [#choose-a-role]

各メンバーの業務に最も合う役割を選択します。役割は後から**設定 → ユーザー管理**で変更できます。各役割のデフォルトの権限は次のとおりです。

| 役割 | デフォルトのアクセス権限 |
|---|---|
| **管理者** | 請求を含むすべての機能と設定にアクセスできます。ワークスペースを作成したユーザーは管理者になります。 |
| **業務状況** | レポート作成と業務の監督のために、全社の情報を閲覧できます。ユーザーの招待と管理、レコードの編集ができますが、レコードの作成と削除はできません。ワークスペースの設定や請求にはアクセスできません。 |
| **上司** | 候補者、企業、コンタクト、求人、商談を作成・管理できます。チームのダッシュボードを閲覧できます。 |
| **プリンシパルコンサルタント**、**シニアコンサルタント**、**コンサルタント** | 候補者、企業、コンタクト、求人、商談を作成・管理できます。この3つの役割には、初期設定で同じ権限が付与されています。 |
| **採用担当者** | 候補者、企業、コンタクト、求人、商談を作成・管理できます。 |
| **リサーチャー** | 候補者を閲覧・追加できます。デフォルトでは、企業、コンタクト、求人にはアクセスできません。 |
| **ユーザー** | 割り当てられたタスクを閲覧・更新するための基本的なアクセス権限があります。デフォルトでは、候補者、企業、求人を閲覧できません。 |

<Note>
  **最高管理者**は予約済みの役割です。**設定 → ユーザー管理**から割り当てることはできません。
</Note>

Team以上のプランでは、管理者が**設定 → 権限**から各役割で実行できる操作を変更できます。[ユーザーの役割](/ja/team/user-roles)と[権限のカスタマイズ](/ja/team/customising-permissions)をご覧ください。

## 利用ユーザー数 [#seats]

プランには、購入した人数分の利用ユーザー枠が含まれます。有効なユーザー1人につき1枠を使用します。すべての枠を使用している場合は、**利用ユーザー数の上限に達しました**というメッセージが表示されます。枠を空けるか追加するまで、他のユーザーを招待できません。

- **利用ユーザー数を追加する。** 管理者は**設定 → プラン**から利用ユーザー数を増やせます。[利用ユーザー数の追加と削減](/ja/billing/adding-removing-seats)をご覧ください。
- **アクセスが不要になったユーザーを無効にする。** ユーザーを無効にすると、その枠を新しいユーザーに使用できます。[ユーザーの無効化と再有効化](/ja/team/deactivating-reactivating)をご覧ください。

<Warning>
  ユーザーを無効にすると利用ユーザー枠に空きができますが、請求額は下がりません。料金は有効なユーザー数ではなく、購入した利用ユーザー数に基づきます。利用ユーザー数を減らして料金を下げるには、**設定 → プラン**で利用ユーザー数を減らしてください。
</Warning>
