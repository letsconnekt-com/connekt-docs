Connektのデータベースには、人脈や会話の記録、長年にわたる業務の成果が蓄積されています。このページでは、Connektがこれらのデータをどのように保護しているかについて、よくある質問にお答えします。

<AccordionGroup>
  <Accordion title="Connektは2段階認証に対応していますか？">
    はい。すべてのプランに2段階認証（2FA）が含まれています。2FAを有効にすると、サインイン時にパスワードに加えて認証アプリのコードが必要になります。パスワードが漏えいしても、それだけではワークスペースにアクセスできません。

    各ユーザーが**設定 → セキュリティ**から自分のアカウントの2FAを有効にします。[セキュリティと2段階認証](/ja/account/security-and-2fa)をご覧ください。
  </Accordion>

  <Accordion title="各ユーザーが閲覧できる情報や実行できる操作を管理できますか？">
    はい。各ユーザーにはロールが割り当てられ、それぞれのロールに権限が設定されています。これにより、各ユーザーは必要な情報だけを閲覧できます。

    Teamプラン以上では、管理者が**設定 → 権限**から各ロールで実行できる操作を細かく調整できます。[ユーザーロール](/ja/team/user-roles)と[権限のカスタマイズ](/ja/team/customising-permissions)をご覧ください。
  </Accordion>

  <Accordion title="ワークスペースで誰が何をしたか確認できますか？">
    はい。**操作履歴**には、ワークスペース全体でのユーザーの操作が**アクティビティ履歴**として表示されます。サインインとサインアウト、レコードの変更、書類に関する操作、休暇申請、添付ファイルなどが含まれます。各イベントには、操作したユーザーと日時に加え、IPアドレス、場所、デバイスが表示されます。

    操作履歴はTeamプランとBusinessプランで利用できます。**設定 → 操作履歴**から開くには、システム管理権限が必要です。[アクティビティと利用状況](/ja/advanced/activity-and-usage)をご覧ください。
  </Accordion>

  <Accordion title="候補者データのスクリーンショット撮影を防止できますか？">
    はい。モバイルアプリで防止できます。管理者は、ワークスペース内の全ユーザーを対象に、Connektモバイルアプリでのスクリーンショット撮影と画面録画を禁止できます。スクリーンショットの防止はデフォルトで有効になっています。

    変更するには、**設定 → セキュリティ**に移動し、**スクリーンショットの防止**スイッチを切り替えます。[セキュリティと2段階認証](/ja/account/security-and-2fa#screenshot-protection-administrators)をご覧ください。
  </Accordion>

  <Accordion title="データは暗号化されますか？">
    はい。ユーザーとConnektの間でやり取りされる通信中のデータは暗号化されます。保存中のデータも暗号化されます。
  </Accordion>

  <Accordion title="データはバックアップされますか？">
    はい。ワークスペースは毎日バックアップされます。
  </Accordion>

  <Accordion title="他の人が自分のアカウントにアクセスしている疑いがある場合は、どうすればよいですか？">
    すぐに次の対応を行ってください。

    1. **設定 → セキュリティ**に移動し、**他のすべてのデバイスからサインアウト**をクリックして、他のすべてのデバイスをサインアウトします。
    2. パスワードを変更します。これにより、すべてのデバイスからサインアウトされます。
    3. 2段階認証をまだ有効にしていない場合は、有効にします。
    4. ワークスペースの管理者に知らせます。

    [セキュリティと2段階認証](/ja/account/security-and-2fa)をご覧ください。
  </Accordion>

  <Accordion title="ここに記載されていないセキュリティに関する質問があります">
    Connektチームにお問い合わせください。チームの情報がどのように取り扱われるかをご説明します。[サポートへのお問い合わせ](/ja/getting-started/getting-help)をご覧ください。
  </Accordion>
</AccordionGroup>
