各推薦には、候補者の選考状況を示すステータスがあります。Connektには19種類のステータスがあり、ステータスメニューでは**初期ステージ**、**面接ステージ**、**最終ステージ**、**その他**の4つに分類されています。

## 初期ステージ [#initial-stages]

| ステータス | 意味 |
|---|---|
| **推薦済み** | 候補者を推薦した状態です。新規の推薦には、デフォルトでこのステータスが設定されます。 |
| **選考中** | クライアントが候補者のプロフィールを確認しています。 |
| **ショートリスト登録済み** | クライアントが候補者をショートリストに登録した状態です。 |

## 面接ステージ [#interview-stages]

| ステータス | 意味 |
|---|---|
| **電話面談** | 選考のための電話面談が予定されているか、完了した状態です。 |
| **1次面接** | 候補者が1次面接の段階にいます。 |
| **2次面接** | 候補者が2次面接の段階にいます。 |
| **3次面接** | 候補者が3次面接の段階にいます。 |
| **最終面接** | 候補者が最終面接の段階にいます。 |
| **技術評価** | スキルテストまたは持ち帰り課題が進行中です。 |
| **プレゼンテーション** | 候補者がプレゼンテーションを準備中、または実施中です。 |

## 最終ステージ [#final-stages]

| ステータス | 意味 |
|---|---|
| **リファレンスチェック** | リファレンスチェックまたは経歴調査が進行中です。 |
| **内定提示済み** | クライアントが内定を提示した状態です。 |
| **内定承諾** | 候補者が内定を承諾した状態です。 |
| **内定辞退** | 候補者が内定を辞退した状態です。 |
| **採用** | 候補者の採用が決まった状態です。推薦から成約を作成すると、Connektが自動的にこのステータスを設定します。 |

<Tip>
  推薦が**内定承諾**または**採用**になると、その推薦から成約を作成できます。[推薦を成約に変換する](/ja/submissions/converting-to-placement)をご覧ください。
</Tip>

## その他 [#other]

| ステータス | 意味 |
|---|---|
| **不採用** | クライアントが候補者を選ばなかった状態です。 |
| **選考辞退** | 候補者が選考を辞退した状態です。 |
| **保留** | 選考が一時停止しています。推薦は**商談**ページで引き続きアクティブとして扱われます。 |
| **選考終了** | その他の理由で選考が終了した状態です。推薦は**商談**ページに表示されなくなります。 |

## 推薦のステータスを変更する [#change-a-submissions-status]

ステータスは3か所から変更できます。いずれも、ステータスを選択するとすぐに変更が保存されます。**保存**ボタンやメモ欄はありません。

<Tabs>
  <Tab title="求人の推薦タブ">
    <Steps>
      <Step title="求人を開く">
        **求人**に移動し、求人を開いて**推薦**タブをクリックします。
      </Step>
      <Step title="ステータスをクリックする">
        **面接段階**列で、候補者のステータスバッジをクリックします。
      </Step>
      <Step title="新しいステータスを選択する">
        **ステータスを更新**メニューからステータスを選択します。
      </Step>
    </Steps>
    **求人の編集**権限が必要です。求人が**表示**、**進行中**、**一部採用決定**のいずれでもない場合、メニューは無効になります。
  </Tab>
  <Tab title="候補者の推薦タブ">
    <Steps>
      <Step title="候補者を開く">
        **候補者**に移動し、プロフィールを開いて**推薦**タブをクリックします。
      </Step>
      <Step title="ステータスをクリックする">
        **ステータス**列で、該当する求人のステータスバッジをクリックします。
      </Step>
      <Step title="新しいステータスを選択する">
        **ステータスを更新**メニューからステータスを選択します。
      </Step>
    </Steps>
    **候補者の推薦情報を編集**権限が必要です。
  </Tab>
  <Tab title="商談ページ">
    <Steps>
      <Step title="商談を開く">
        サイドバーの**商談**をクリックします。**パイプライン**タブが開きます。
      </Step>
      <Step title="ステータスを変更する">
        **テーブル**表示では、**ステータス**列のバッジをクリックしてステータスを選択します。**カンバン**表示では、カードを別の列にドラッグします。
      </Step>
    </Steps>
    **案件の進捗管理**権限が必要です。**選考終了**を選択すると、候補者がアクティブなパイプラインから外れるため、Connektに確認画面が表示されます。
  </Tab>
</Tabs>

ステータスが**内定承諾**または**採用**に変わると、推薦を成約に変換できることを知らせるメッセージがConnektに表示されます。**推薦**タブでは、このメッセージに**成約を作成**ボタンが表示されます。

<Note>
  Connektは、ステータスの変更をその都度、候補者の**履歴**タブに記録します。
</Note>

## 商談ページへのステータスの影響 [#how-status-affects-the-deals-page]

- **商談**ページには、デフォルトで14種類のアクティブなステータスが表示されます。初期ステージと面接ステージのすべてに加え、**リファレンスチェック**、**内定提示済み**、**内定承諾**、**保留**が対象です。
- **内定辞退**、**不採用**、**選考辞退**、**選考終了**、**採用**は、そのステータスで絞り込まない限り表示されません。
- 各商談には、Connektがステータスに基づいて設定する確度があります。確度の仕組みと手動で変更する方法については、[商談ボード](/ja/submissions/pipeline-board)をご覧ください。
