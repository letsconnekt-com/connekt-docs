**商談**ページには、進行中の推薦が商談として表示され、各商談のステージ、確度、金額を確認できます。パイプラインの確認、レコードを開かずに行う商談の更新、売上予測に使用します。サイドバーの**商談**をクリックして開きます。

## 商談ページのタブ [#tabs-on-the-deals-page]

| タブ | 表示内容 | 閲覧に必要な権限 |
|---|---|---|
| **パイプライン** | 進行中の推薦（商談）。このページでは、このタブについて説明します。 | 商談の表示権限のいずれか |
| **自分の成約** | 自分がメインのリクルーターを務める成約。 | **自分の案件の表示**または**担当案件の表示** |
| **すべての成約** | 会社全体の成約。 | **会社全体の案件の表示** |

成約のタブについては、[成約を作成する](/ja/placements/creating-a-placement)と[成約と支払いのステータス](/ja/placements/placement-statuses)を参照してください。

## 表示される商談 [#which-deals-appear]

**パイプライン**タブには、次の14の進行中ステータスにある推薦が表示されます。

- **初期ステージ：** 推薦済み、書類選考中、ショートリスト選出
- **面接ステージ：** 電話スクリーニング、1次面接、2次面接、3次面接、最終面接、技術評価、プレゼンテーション
- **最終ステージ：** リファレンスチェック、内定提示済み、内定承諾
- **その他：** 保留

**内定辞退**、**不採用**、**選考辞退**、**選考終了**、**採用**の推薦は、ステータスフィルターでそのステータスを選択した場合にのみ表示されます。推薦に成約が作成されると、その時点でパイプラインから除外されます。

## 統計カード [#stats-cards]

上部のカードには、現在のフィルターに一致する商談の集計が表示されます。

| カード | 表示内容 |
|---|---|
| **進行中の面接** | **1次面接**から**内定提示済み**までの商談数です。 |
| **パイプライン金額** | 選択した通貨に換算した、商談の見積金額の合計です。 |
| **平均確度** | 商談全体の平均確度です。 |
| **配分のある商談** | 分担商談の件数です。 |
| **予測対象の商談** | 確度が70%以上の最終段階にある商談の件数です。 |
| **予測請求額** | 選択した通貨に換算した、予測対象の商談の合計金額です。 |

右上の通貨ボタンで、金額の表示方法を選択します。**数値の表示通貨**メニューでは、**会社の通貨**、**自分の通貨**を選択できます。オフィスを選択している場合は、そのオフィスの通貨も選択できます。デフォルトは会社の通貨です。管理者が**設定 → 売上・為替**で設定します。

## パイプラインを絞り込む [#filter-your-pipeline]

| 操作項目 | 機能 |
|---|---|
| **商談を検索...** | 候補者名、求人名、企業名、**推薦先**で商談を検索します。 |
| チームメンバー選択 | 表示するパイプラインの対象者を選択します。マネージャーは**自分のパイプライン**、**チームメンバー全員**、各チームメンバーを選択できます。**会社全体の案件の表示**権限を持つユーザーは、**すべてのパイプライン**、**自分のパイプラインのみ**、任意のユーザーを選択できます。他のユーザーの商談を閲覧できる場合にのみ表示されます。 |
| ステータスフィルター | **すべてのステータス**、または終了済みを含む単一のステータスを表示します。 |
| **全体表示** / **企業ビュー** / **候補者ビュー** | どの担当者情報を基準にするかを選択します。詳しくは下記を参照してください。 |
| オフィスとチームのメニュー | 管理者とマネージャーは、右上でパイプラインをオフィスまたはチームに絞り込めます。 |

各ビューでは、選択したユーザーを基準に次の商談が表示されます。

- **全体表示：** 商談、候補者、企業のいずれかの担当者として、そのユーザーが関わるすべての商談を表示します。
- **企業ビュー：** そのユーザーの担当企業で選考中の候補者を表示します。候補者の担当者は問いません。
- **候補者ビュー：** そのユーザーが担当する選考中の候補者を表示します。企業の担当者は問いません。

<Note>
  **すべてのパイプライン**を表示している間は、**企業ビュー**と**候補者ビュー**は適用されません。先にユーザーを選択してください。
</Note>

## テーブルとカンバンを切り替える [#switch-between-table-and-kanban]

フィルターの横にある**テーブル**または**カンバン**をクリックします。デフォルトは**テーブル**です。Connektは、このブラウザーでの選択を記憶します。

<Tabs>
  <Tab title="テーブル">
    各行が1件の商談を表します。列は、**候補者**、**ポジション**、**企業**、**商談種別**、**ステータス**、**確度**、**商談金額**、**採用担当者**、**コメント**、**最終活動**、**操作**です。

    **内定承諾**または**採用**の行は緑色で強調表示されます。**保留**の行はオレンジ色で強調表示されます。
  </Tab>
  <Tab title="カンバン">
    各列がステータスを、各カードが商談を表します。カードを別の列にドラッグすると、ステータスを変更できます。

    使用しない列を非表示にするには、**列**をクリックし、**表示する列**で該当するステータスのチェックを外します。列の選択はConnektのアカウントに保存されます。折りたたまれた列に非表示の商談がある場合は、その件数を示すメッセージと**すべて表示**リンクが表示されます。
  </Tab>
</Tabs>

## 商談を直接編集する [#edit-deals-inline]

**案件の進捗管理**権限がある場合は、テーブルまたはカンバンカードで次の項目を直接編集できます。この権限がない場合は、閲覧のみ可能です。

| 項目 | 編集方法 |
|---|---|
| **ステータス** | バッジをクリックし、ステータスを選択します。**選考終了**を選択すると、確認を求められます。 |
| **商談種別** | **単独商談**または**分担商談**を選択します。 |
| **確度** | パーセント値をクリックし、0から100までの値を入力して**保存**をクリックします。 |
| **商談金額** | 金額をクリックし、**通貨**と**金額**を指定してEnterを押します。キャンセルするにはEscapeを押します。 |
| **コメント** | コメントをクリックして**コメントを編集**を開きます。 |

### 確度の仕組み [#how-probability-works]

Connektは各商談のステータスに基づいて確度を設定し、ステージが進むほど高い値を設定します。**確度を編集**で、この値を手動で変更できます。ステータスに基づく値に戻すには、**リセット**をクリックします。商談を**内定承諾**、**採用**、**内定辞退**、**不採用**、**選考辞退**、**選考終了**に移動すると、確度は必ず再計算されます。

## 商談の詳細を表示する [#view-deal-details]

テーブルでは、**操作**列の**⋯**をクリックして**詳細を表示**を選択します。カンバンカードでは、カードのメニューを使用します。**商談の詳細**パネルが開き、**歩合報酬**タブが表示されます。このパネルには**ステージ履歴**タブもあります。

**歩合報酬**タブは閲覧専用で、**商談の概要**、**金額の内訳**、**コミッションの配分**、**コメント**、**概要**が表示されます。**コミッションの配分**には、候補者と企業の担当者に基づく配分の見積もりが表示されます。実際の配分は成約で設定します。[商談の配分](/ja/placements/deal-splits)を参照してください。

<Note>
  すでに**採用**となっている商談では、**詳細を表示**を選択すると、代わりに候補者のプロフィールが開きます。
</Note>

## 商談から成約を作成する [#create-a-placement-from-a-deal]

商談が**内定承諾**または**採用**になったら、**⋯**をクリックして**成約を作成**を選択します。**案件の作成**権限が必要です。[推薦を成約に変換する](/ja/submissions/converting-to-placement)を参照してください。
