**署名**の各書類には、署名手続きの進捗を示すステータスがあります。レビュー担当者が承認したり、署名者が署名したりすると、Connektが自動で更新します。**署名**の一覧は、ステータスと種類（**自分で署名**または**署名を依頼**）で絞り込めます。

## ステータス一覧 [#status-reference]

| ステータス | 意味 |
|---|---|
| **下書き** | 書類は作成されていますが、まだ送信されていません。署名者やフィールドを変更できます。 |
| **レビュー待ち** | 書類のレビューを依頼し、レビュー担当者の承認または却下を待っています。 |
| **署名待ち** | 書類は送信されていますが、まだ誰も署名していません。**署名**の一覧では**保留中**と表示されます。 |
| **一部署名済み** | 1人以上の署名者が署名済みで、ほかの署名者の署名が必要です。**署名**の一覧では**一部署名済み**と表示されます。 |
| **完了** | 全員が署名済みです。署名済みPDFと完了証明書を利用できます。 |
| **期限切れ** | 外部署名者が14日以内に署名しませんでした。署名リンクは使用できなくなります。 |
| **キャンセル済み** | 誰かが書類をキャンセルしました。署名リンクは使用できなくなります。 |

## 外部署名者へのリマインダーと有効期限 [#reminders-and-expiry-for-external-signers]

Connektが外部署名者にメールを送信した時点から、14日間の署名期限が始まります。

| 経過日数 | 動作 |
|---|---|
| 3 | 署名者に最初のリマインダーが届きます。 |
| 7 | 署名者に2回目のリマインダーが届きます。 |
| 10 | 署名者に最後のリマインダーが届き、書類の作成者に通知が届きます。 |
| 14 | まだ署名していない場合、書類は**期限切れ**になります。作成者にメールが送信されます。 |

署名者の**再送信**をクリックすると、新しいリンクが送信され、その時点から14日間の署名期限が再び始まります。

<Note>
  内部署名者にはリマインダーは送信されません。また、内部署名者のリンクが原因で書類が期限切れになることはありません。内部署名者のリンクは30日間有効です。
</Note>

## 各ステータスでできる操作 [#what-you-can-do-at-each-status]

書類を変更するには、その書類に対する**管理可能**権限が必要です。書類の作成者には常にこの権限があります。[書類の管理](/ja/documents/managing-documents)をご覧ください。

<AccordionGroup>
  <Accordion title="下書き">
    - **フィールドを編集**をクリックして、署名者やフィールドを変更します。
    - 書類を送信するか、レビューを依頼します。
    - CCの宛先を追加し、チームと共有します。
    - **⋯**メニューから**書類をキャンセル**または**削除**を選択します。

    レビュー担当者が書類を却下した場合は、**修正のため差し戻し**バナーに理由が表示されます。修正して再送信してください。
  </Accordion>

  <Accordion title="レビュー待ち">
    - レビュー担当者または管理者であれば、**承認**または**却下**できます。[送信前の書類レビュー](/ja/documents/review-before-sending)をご覧ください。
    - レビュー中は署名者やフィールドを変更できません。
    - **⋯**メニューからのキャンセルや削除は引き続き可能です。
  </Accordion>

  <Accordion title="署名待ちと一部署名済み">
    - **署名者**と**アクティビティ**で進捗を確認します。
    - 未署名の外部署名者の横にある**再送信**をクリックして、新しいリンクをメールで送信します。
    - 内部署名者として自分の署名順が来たら、**今すぐ署名**をクリックします。
    - CCの宛先を追加または削除します。
    - **⋯**メニューから**書類をキャンセル**または**削除**を選択します。

    送信後はフィールドや署名者を変更できません。
  </Accordion>

  <Accordion title="完了">
    - **⋯**メニューから**書類をダウンロード**を選択すると署名済みPDFを、**証明書をダウンロード**を選択すると完了証明書をダウンロードできます。
    - **企業に紐付け**を選択して、書類を企業に紐付けます。
    - **削除**を選択して、書類をアーカイブまたは完全に削除します。

    署名済みPDFがまだ生成されていない場合は、**⋯**メニューに**最終処理を再試行**が表示されます。この操作で署名済みPDFを再生成します。
  </Accordion>

  <Accordion title="期限切れとキャンセル済み">
    署名手続きは終了しており、署名リンクは使用できません。書類を再開したり、再送信したりすることはできません。

    やり直すには、**新規書類**をクリックしてファイルを再度アップロードします。キャンセルした書類は**署名**の一覧から削除されます。
  </Accordion>
</AccordionGroup>

<Warning>
  キャンセルは取り消せません。署名者はリンクを使用できなくなり、書類は**署名**の一覧に表示されなくなります。
</Warning>
