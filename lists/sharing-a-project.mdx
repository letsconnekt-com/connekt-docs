Connekt lets you share a candidate shortlist directly with a client through a clean, branded portal — no Connekt account or login required on their end. You generate a magic link with an expiry date and send it however you like. This feature is available for **Projects only**; Talent Pools do not currently support external client sharing.

## What the Client Sees

When a client opens the shared link, they land on a portal that shows:

- A **branded view** of the candidate profiles included in the project
- **Candidate contact details** based on your sharing settings
- A read-only experience — the client **cannot make changes** to anything, and they have no access to any other part of Connekt

The client does not need to create an account or sign in to Connekt at any point.

## Sharing a Project

<Steps>
  <Step title="Open the project">
    Go to **Lists → Projects** and open the project you want to share.
  </Step>
  <Step title="Start sharing">
    Click **Share with Client**.
  </Step>
  <Step title="Set an expiry date">
    Choose an **expiry date** for the link. The portal will stop working automatically when this date passes — no manual action needed.
  </Step>
  <Step title="Copy and send the link">
    Copy the generated **magic link** and send it to your client contact via email or any other channel.
  </Step>
</Steps>

<Tip>
  Always set an expiry date that matches the timeline of the search. A link that outlasts the role means a client could revisit an outdated shortlist — revoke access or let the expiry do the work.
</Tip>

## Managing Access

<Accordion title="Revoke access before the expiry date">
  If the role closes early or you need to pull back access for any reason, you can revoke the link immediately.

  1. Open the project.
  2. Go to the project settings (pool settings panel).
  3. Click **Revoke Client Access**.

  The link is invalidated instantly — the client will see an error if they try to use it again.
</Accordion>

<Accordion title="Generate a new link for the same client">
  If you need to refresh the link — for example, after updating the shortlist — share the project again. A new link is generated and replaces the previous one automatically.
</Accordion>

<Accordion title="Check when the current link expires">
  Open the project settings panel. The current link's expiry date is shown there so you can quickly confirm whether access is still active.
</Accordion>

<Warning>
  Client sharing is only available for **Projects**. If you need to share candidates from a Talent Pool, create a new Project, add the relevant candidates to it, and share from there instead.
</Warning>
